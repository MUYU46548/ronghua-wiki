# 概念总览

沫峪流笙是绒花计划中的一种**集成式冒险领域**，由多个独立且风格迥异的[[笙境]]副本构成。除了固定地图外，还可能存在周期性波动、随机显现的特殊空间结构，唯有特定条件下才会对特定个体开放。

# 定位与性质

- 触发机制：当剧情推进至某些节点（角色心境变化、遭遇特定事件时），沫峪流笙可能会开启入口。
- 资源价值：每个笙境都可能产出独特的资源，部分资源与主线剧情的关键线索直接挂钩。
- 难度层级：每个笙境都可能包含特殊机制与解谜要素，侧重剧情理解与环境互动，而非纯粹战斗强度考核。
- 常驻性：不随主线完结而消失，新笙境可能随世界观拓展陆续显现，旧笙境可重复进入但奖励与叙事反馈会变化。

# 设计框架

每个笙境遵循统一模板，但内容独立：

1. 主题标签：暗示核心氛围与冲突。
2. 环境基底：一种主导的生态或物理规则，如无限下行的阶梯、记忆构成的河流、以声音为重力锚点的废墟。
3. 特殊机制：可能存在非战斗向的特殊互动规则。
4. 叙事锚点：与某位角色的过去、未来、平行可能性相关的碎片故事。
5. 引导存在：可能残存意识或受困于规则中的某个人物。
6. 探索成果：可能获得丰厚奖励。

# 与主线的关联方式

- 线索埋设：某个笙境中获取的信息残片，恰好对应主线某段疑点的侧面解答。
- 角色成长：角色在笙境中的经历会改变其部分技能或思维模式。
- 因果扰动：在笙境中作出的选择，可能对外部产生影响。
- 伏笔前置：早期可进入的低难度笙境，展示某种意象或人物剪影，在后期主线揭示时形成回响。
