# 基本规则

创建重定向页仅限**必要情况**。

创建于 `重定向/` 文件夹，仅当满足以下**全部条件**：

- 该词高频被用户输入或搜索，如旧称、俗称、对某一类事物的笼统称呼。
- 明确指向唯一设定项（无歧义），含歧义内容适用于[[同名与歧义处理规则]]。
- 不适合仅靠别名（aliases）解决，例如希望点击后直接跳转。

不推荐为**模糊概念**单独建页，如“古代武器”“低阶法师”等笼统词。

- 若无独立设定：使用标签，或在索引页中作为子项列出。
- 若有明确定义：可放入 `设定/` 并命名为 `设定/古代武器体系.md`。
- 例外情况：约定俗称的称呼，且不适合单独建立页面。

# 消歧义与重定向之辨析

| 场景             | 处理方式                        | 示例                                  |
| -------------- | --------------------------- | ----------------------------------- |
| 一个词对应多个不同概念    | 消歧义页（放在 `索引/消歧义导航/`），隶属索引系统 | `设定/天气/风暴.md`中，列出“风暴（天气）”与“风暴（佣兵团）” |
| 一个词是另一个词的别名或简称 | 使用aliases或重定向页              | “NEC”指向`设定/北方帝国联盟`                  |
| 一个词太泛，无具体指代    | 暂不建页，改用标签或索引                | 用`#小型生物`标记小型生物                      |

 > [!tip] 消歧义页本身是一种特殊索引。
 
# 维护与清理

- 每季度检查一次`重定向/`文件夹，删除过时或冗余条目。
- 若某重定向词后来发展出独立设定，将其移入`设定/`并更新链接。
- 避免在`重定向/`中添加任何解释性内容，它只发挥指示作用，不是承载主要信息的正文页面。
