# 批量升级人际关系区块（框架重构，不修改内容）

## 1.任务目标

将指定角色文档中旧的三级标题 `### 人际关系` 及其下的所有内容，升级为新的四级标题结构：

- `#### 重要关系`
- `#### 一般关系`
- `#### 其他关系`

**所有旧内容必须完整保留，只做搬迁，不做任何语义修改。**

## 2.固定配置

- **角色文档根目录**：`E:/图书馆/ROSA/03 设定/01 人物/02 新作人物/`
- **关键词分流规则**（按优先级）：
	- **重要关系**：`挚友`、`好友`、`伴侣`、`亲人`、`恩师`、`宿敌`、`师父`、`徒弟`、`伙伴`
	- **一般关系**：`同事`、`同学`、`盟友`、`搭档`、`熟人`、`相识`、`同僚`
	- **其他关系**：不包含上述关键词（兜底）

## 3.核心逻辑（纯机械搬运）

1. 对每个角色文档，查找 `### 人际关系`，截取其下方所有内容（直到下一个 `###` 或 `##`）。
2. 按段落（空行分隔）拆分，根据关键词分流至对应子标题。
3. 删除旧区块，插入新结构（标题与正文之间保留空行）。
4. 跳过条件：

- 如果文档中已存在`#### 重要关系`标题（说明已升级），则跳过该文件。
- 如果`### 人际关系`不存在，则跳过。

格式特别强调：

- 所有子标题（#### 重要关系/一般关系/其他关系）与下方正文之间**必须保留一个空行**。
- 不同分类之间也保留一个空行（即标题与标题之间空一行）。
- 确保只有一个空行。

严格遵循以下模板：

```markdown
### 人际关系

#### 重要关系

#### 一般关系

#### 其他关系

```

## 4.输出要求（省流模式）

- 每处理完一个，输出一句摘要：`✅ [角色名] 人际关系区块已升级（X 段内容 → 重要/Y 段，一般/Z 段，其他/W 段）。`
- 若跳过：`⚠️ [角色名] 跳过：原因（已升级/无旧人际关系区块）。`
