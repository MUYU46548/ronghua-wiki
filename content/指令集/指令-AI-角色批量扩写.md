# 扩写规范

- 允许在基础素材上进行合理的创作扩写，但必须基于已有世界观和素材逻辑。
- 如果素材中完全未提及某个字段，可以自行创作，但不得违背已有素材。
- 如果素材有线索但不完整，可以合理推断补充，不需要标注。

# 执行步骤

1. 读取模板，理解字段结构。
2. 读取所有必需素材文件。
3. 处理第一批（[角色列表]），生成文档。
4. 完成后暂停，等待“继续”指令。
5. 收到“继续”后，处理下一批。
6. 重复直至所有批次完成。

# 约束

- 严禁读取、搜索、提及、猜测或生成任何未在“文件与路径”中明确列出的文件。
- 严禁使用通配符（如 *.md）或模糊路径进行搜索或遍历。
- 严禁编造不存在的文件名。若某个角色的占位符文件不存在，直接跳过该角色，并在最终报告中注明跳过原因。
- 如果某个必需素材文件不存在，立即暂停任务并告知我缺失的文件名，不要试图用其他文件替代或自行推断内容。
- 只写入沙盒目录，不修改任何其他文件。
- 每个角色独立成文，不合并。
- 下一批开始前，不得读取或处理下一批角色。

# 工具调用要求

- 对于每个角色，**必须实际调用 `write_file` 工具**将文档写入输出目录。
- 写入成功后，**调用 `read_file` 工具**读取该文件的前 20 行，以验证文件确实存在。
- 严禁在对话中仅用文字“描述”写入过程（例如“已写入”或“已完成”），而不实际调用工具。
- 如果 `write_file` 或 `read_file` 调用失败，立即暂停并报告错误，不得继续处理下一个角色。

## 可选方案

如果工具调用功能不可用或频繁失败，请改为在对话中直接输出完整的 Markdown 内容，每份文档用 `---` 分隔。输出完成后，请告知“已全部输出，请手动保存”。
