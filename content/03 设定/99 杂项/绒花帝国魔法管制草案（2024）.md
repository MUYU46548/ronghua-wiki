在幻境世界中，魔法存在并被视作潜在的巨大威胁，无论是社会不稳定、个人安全还是力量失衡。为了维护绒花帝国的稳定，我们迫切需要可以实施的对魔法使用者进行制裁和限制、阻止魔法扩散的严厉措施。

本草案由绒花宫与魔法使自律委员会共同起草，经由双方代表仔细阅读并核对后提交。绒花宫方面保留有最终解释权与执行权。在取得进一步的指令之前，魔法使自律委员会的任何成员不得擅自行动。

# 总则

控制源头、限制传播、监控使用、严惩违规。

# 第一节

源头控制：扼杀魔法知识的传播。

1. **严格的知识管制与焚书令：**
    - **魔法典籍禁令：** 所有记载魔法理论、咒语、符文、仪式、炼金配方、魔药制作的书籍、卷轴、石板等均被列为危害绒花帝国的违禁品。公开持有、传播、复制均属重罪。
    - **系统性销毁：** 设立专门机构（如“净化小组”、“魔法回收部”）负责搜寻、收缴并销毁一切魔法文献。历史上著名的魔法图书馆、学院遗址被严密封禁监控或物理摧毁。
    - **口述禁令：** 严格禁止以任何形式（包括诗歌、歌谣、寓言、暗语）口头传授魔法知识。教导魔法等同于叛国或反人类罪。
    - **记忆审查/抹除：** 对疑似接触过核心魔法知识的人，使用特殊手段（魔法或非魔法）进行记忆审查甚至强制性记忆抹除。因执行公务不得不有所涉猎可适当予以放宽。
2. **魔法学徒制与师承关系的彻底禁止：**
    - 禁止魔法传授与扩散。任何形式的师徒传承关系都被定为非法结社。举报师徒关系可获得巨额赏金。
    - 试图寻找导师或招收学徒的行为本身就会招致严厉惩罚。
3. **魔法天赋的压制与净化：**
    - **强制登记与监控：** 所有新生儿或特定年龄段的儿童（如12岁）必须接受魔法天赋检测。检测出天赋者强制登记在册，终身受到特殊监控（如佩戴抑制手环、定期报到、限制活动范围等）。
    - **天赋抑制：** 开发并强制使用长期或永久性的魔法抑制手段：
        - **抑制药剂：** 定期服用或注射，暂时或永久削弱魔力感应和操控能力，尽管可能伴随副作用（精神萎靡、身体虚弱）。
        - **抑制符文/烙印：** 在身体关键部位（额头、心脏、脊椎）刻印或烙印永久性抑制符文，阻断魔力流动，过程痛苦且不可逆。
        - **抑制器具：** 强制佩戴魔力抑制项圈、手镯或植入物，可远程监控甚至触发惩罚（电击、剧痛）。
    - **“天赋净化”计划：** 若某些紧急情况发生，可能推行实验性的“治疗”或“手术”，在精神层面对魔法进行强力压制。

# 第二节

魔法物品与媒介的严格管制。

1. **魔法物品制造、流通禁令：**
    - 禁止任何个人或组织制造、销售、交易魔法物品（法杖、魔杖、符文石、魔法卷轴、附魔武器/护甲、炼金药剂、魔力水晶等）。
    - 现存魔法物品被列为违禁品，强制收缴、封存或销毁。私藏即重罪。
2. **魔力源泉的封锁与污染：**
    - **地脉节点封印：** 识别并动用巨大资源（工程或魔法）封印自然界的魔力富集点（地脉节点、元素泉眼、星界裂隙）。
    - **环境“去魔化”：** 在关键区域（城市、要塞、农田）大规模铺设或喷洒能吸收、干扰或中和环境魔力的物质（如“禁魔石”粉末、特殊炼金溶液），制造“无魔区”。
    - **污染魔力源：** 极端情况下，向重要的天然魔力源注入有毒物质或混乱能量，使其变得危险、不稳定或无法利用。
3. **施法材料的垄断与禁用：**
    - 将常见且关键的施法材料（特定草药、矿物、生物器官、宝石）列入严格管控清单，禁止民间流通。仅允许官方机构（研究或执法部门）在严密监控下使用微量库存。
    - 培育或采集这些材料均属非法。

# 第三节

对现有施法者的监控、限制与规训。

1. **强制登记与分级管理制度：**
    - 所有已知施法者必须在“魔法管理署”或类似机构进行详细登记（能力类型、强度、危险性评估）。根据威胁等级（如：无害级、受控级、危险级、高危级）实施不同强度的监控和限制。
    - 定期（如每月、每季度）强制报到，接受审查和能力测试。
2. **“许可施法”制度：**
    - 在极少数严格限定的情况下（如为国家服务的医疗、防御、研究），施法者可以申请“施法许可证”。许可证严格限定：
        - **地点：** 只能在指定、高度屏蔽的“施法室”或特定区域。
        - **时间：** 限定时段。
        - **法术类型：** 仅限批准的、低风险、有实用价值的法术（如治疗微伤、元素生火）。
        - **监督：** 必须在反魔法执法人员或监控法阵的严密监视下进行。
    - 任何未经许可的施法行为，无论目的或结果，均被视为犯罪。
3. **“魔法印记”与追踪：**
    - 强制所有登记施法者佩戴或植入魔法印记（徽章、皮下芯片、魔法烙印）。该印记：
        - **身份标识：** 清晰显示其施法者身份和等级。
        - **定位追踪：** 可被执法机构远程追踪位置。
        - **施法报警：** 当侦测到主动施法行为（即使是最微弱的）时，自动向执法中心发出警报。
        - **抑制功能：** 可由授权人员远程激活，暂时或永久性抑制其能力（作为惩罚或拘捕手段）。

# 第四节

执法与惩戒：建立强大的反魔法力量。

1. **专门的反魔法执法机构：**
    - **名称示例：** “禁魔卫队”、“保卫者”、“净魔审判官”。
    - **组成：**
        - **精锐战士：** 装备反魔法装备（2022年后制式装备）。
        - **前施法者“猎巫人”：** 招募少量高度忠诚、接受过严格“净化”和思想改造的前施法者，利用其知识追踪、对抗同类。他们自身受到更严密的监控和抑制。
        - **技术专家：** 研发、维护反魔法设备、侦测法阵和抑制装置。
        - **审讯者：** 专门针对施法者进行审讯，可能使用特殊手段（包括精神魔法或药物）。
    - **权力：** 拥有超越普通执法机构的权力，可随时拘捕、审讯施法者嫌疑人，搜查可疑地点，无需常规授权。
2. **严酷的刑罚：**
    - **轻微违规（如未登记）：** 罚款、精神控制、短期监禁、加强抑制措施。
    - **未经许可施法/私藏魔法物品：** 长期监禁（在特殊禁魔监狱）、强制劳动、永久性强化抑制（如更高级的烙印或植入物）、流放至环境恶劣的“废魔区”。
    - **传授魔法知识：** 视同叛国或反人类罪，刑罚极重：终身监禁（在完全禁魔的绝望牢笼）、**强制“天赋剥离”手术/仪式（极可能致命或致残）**、公开处决以儆效尤。
    - **大规模破坏/反抗：** 无需审判，反魔法执法机构有权当场格杀。
3. **举报制度与连坐：**
    - 鼓励民众举报任何疑似魔法活动、施法者或私藏魔法物品的行为。举报有重赏，知情不报则可能面临严厉惩罚（罚款、监禁）。
    - 对于传授魔法者，其直系亲属、朋友甚至邻居都可能受到牵连（调查、监控、惩罚），以加强打击力度。

# 第五节

社会与文化层面的压制。

1. **污名化与恐惧宣传：**
    - 官方宣传机器持续将魔法描绘为：
        - **灾难之源：** 历史上的战争、瘟疫、天灾都被归咎于魔法的滥用或失控。
        - **邪恶诱惑：** 魔法是堕落、疯狂、与非人力量交易的象征。施法者被妖魔化为“异端”、“怪物”、“社会毒瘤”。
        - **不稳定因素：** 强调魔法力量的不可控性对普通人的威胁。
    - 任何对魔法时代或人物的怀旧、赞美或学术研究都被严格禁止。
2. **宗教/意识形态工具化：**
    - 将压制魔法纳入国家核心意识形态或主流宗教教义。例如：
        - 宣称魔法是“对神定秩序的亵渎”。
        - 将“无魔社会”描绘成唯一纯洁、安全、符合“天道/神意”的理想状态。
        - 把反魔法斗争神圣化，执法者成为“神圣秩序的捍卫者”。
3. **“无魔区”的设立：**
    - 在核心城市、行政中心、重要工农业区、军事基地周围建立大型的“无魔区”。这些区域：
        - **强力禁魔法阵覆盖：** 区域内魔法效果被极大削弱或完全失效。
        - **物理屏障：** 设有检查站、围墙，严格审查进出人员（特别是施法者）。
        - **优先发展：** 集中资源建设，作为“安全模范区”展示。施法者通常被禁止进入或在严密监控下短暂停留。
