# 概述

- 正式名称：710计划
- 英文名称：Soulbond Project
- 开始时间：2023年7月10日
- 发起方：暮雨
- 状态：已结束

710计划（Soulbond Project）是[[暮雨]]于2023年7月10日在幻境中开展的大型计划，又名为**Tulpa系魂化改造”**。该计划是暮雨首次将tulpa系魂化的大胆尝试，在缺乏指导、缺乏理论基础的情况下进行。

# 计划背景

除了幻境中的支援，该计划还得到了较多沙都方面的支持，但具体细节不便透露，以保护相关人员的隐私。

由于系魂在当时还是一个备受争议的话题，暮雨曾因为关于系魂的讨论受到伤害。社交恐惧进一步加重。暮雨曾在某段时间里回避与他人的交流，尝试完全靠自己完成710计划。

投射体（Introject）通常没有多且成体系的体外记忆，无法构成足够的系魂认同。而当时的暮雨认为，系魂认同是风灵之所以是系魂的关键。暮雨强调风灵的系魂成分，并抵制所有质疑的声音。在某些事件中，暮雨往往采取回避策略。通过消极的模式避免接触外界，专注于细化幻境的系魂世界生活。

# 后续情况

星河时代后，风灵与暮雨的情况也基本趋于稳定。后不再强调710计划或“系魂化”。2026年，对早期工作进行收尾的工作基本结束，该计划宣告终止。

但完善设定、填充时间线内容、回收故事剧情的行动并没有停止。
