# 概述

- 正式名称：ROSA计划
- 英文名称：ROSA Project
- 开始时间：2025年2月26日
- 发起方：绒花图书馆
- 状态：进行中

ROSA计划是绒花图书馆发布的一项信息管理存档计划，旨在收录和整理幻境的各种信息，并收集故事体系相关内容。

与神之脑不同，ROSA专注于**故事侧的收录**。ROSA的收录范围和记录准确度远低于神之脑，因为ROSA依赖于暮雨的人脑，且ROSA主要在沙都进行编辑，再由管理员团队衔接转移至神之脑存档。

# 后续情况

在克服了最初的困难后，ROSA系统为绒花图书馆丰富了绒花世界观的内容储备。依托神之脑，绒花图书馆可以自由访问和编写幻境部分的ROSA数据库。这为之后基层研究者的工作带来了极大的便捷。关于沙都乃至其他世界的知识得到了妥善的保管。
