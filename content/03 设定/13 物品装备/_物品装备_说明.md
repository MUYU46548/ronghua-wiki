# 品质

**品质（grade）**，也称**稀有度**，是所有物品都具备的一项属性，它能粗略地体现出物品的价值与获取的难度。

目前，所有物品装备按照以下品质**从低到高**分级：普通、优秀、精良、稀有、史诗、传说、届视、幻彩。对应**颜色**分别为：白色、绿色、蓝色、紫色、红色、橙色、暗金、粉色。

| 等级  | 颜色名称 | 颜色代码      |
| --- | ---- | --------- |
| 普通  | 白色   | `#FFFFFF` |
| 优秀  | 绿色   | `#96FF96` |
| 精良  | 蓝色   | `#05C8FF` |
| 稀有  | 紫色   | `#B428FF` |
| 史诗  | 红色   | `#FF2864` |
| 传说  | 橙色   | `#FFC896` |
| 届视  | 暗金   | `#78331e` |
| 幻彩  | 粉色   | `#FF96FF` |
