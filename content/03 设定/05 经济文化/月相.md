# 月相分类及顺序

乐园星的月相按时间顺序可分为以下8个主要阶段：

1. 新月（New Moon）
    - 时间：月球位于太阳和乐园星之间，未被照亮的一面对向乐园星。
    - 可见性：几乎不可见（除非发生日食）。
    - 别称：朔月、晦月（阴历每月初一）。
2. 蛾眉月（Waxing Crescent）
    - 时间：新月后1-2天至约7天。
    - 特征：右侧出现细弯月牙，逐渐变宽。
3. 上弦月（First Quarter）
    - 时间：新月后约7.4天。
    - 特征：右侧半圆被照亮，形如半圆（实际是1/4的月相周期）。
    - 别称：弦月（阴历初七或初八）。
4. 渐盈凸月（Waxing Gibbous）
    - 时间：上弦月至满月之间（约第8-14天）。
    - 特征：右侧大部分被照亮，仅左侧边缘阴影。
5. 满月（Full Moon）
    - 时间：月球位于乐园星和太阳的相反方向，完全被照亮。
    - 可见性：整夜可见，亮度最高。
    - 别称：望月（阴历十五或十六），十六日称十六夜。
6. 渐亏凸月（Waning Gibbous）
    - 时间：满月后至下弦月之间（约第16-21天）。
    - 特征：左侧大部分被照亮，右侧边缘阴影。
7. 下弦月（Last Quarter）
    - 时间：约第22.1天。
    - 特征：左侧半圆被照亮，形如半圆。
8. 残月（Waning Crescent）
    - 时间：下弦月至新月之间（约第23-29天）。
    - 特征：左侧细弯月牙，逐渐变窄至消失。
    - 别称：亏眉月。

约29.53天完成一个周期，称为**朔望月**。

各月相特点与阴历日期对应表如下：

| 月相名称 | 阴历日期  | 特点与位置                   |
| ---- | ----- | ----------------------- |

# 特殊月相现象

1. 超级月亮（Supermoon）
    - 成因：月球位于近地点（距离乐园星最近）时恰逢满月或新月。
    - 效果：满月比平常大14%、亮30%。
2. 蓝月（Blue Moon）
    - 定义：一个阳历月内出现两次满月，或一个季节中出现四次满月时的第三次满月。
    - 频率：约每2.7年一次（与颜色无关，实际月亮不显蓝色）。
3. 黑月（Black Moon）
    - 定义：一个阳历月内出现两次新月，或没有满月的月份（罕见）。
    - 意义：与天文观测或占星文化相关。
4. 血月（Blood Moon）
    - 定义：天空变成红色，暗红色的月亮升起。
    - 成因：月全食时，乐园星大气散射蓝光，红光折射到月球表面，呈现暗红色。
    - 文化关联：常被认为是极为不祥的征兆。有人认为血月有一种魔力，能吸引怪物蜂拥而来。传说一些生物会在血月的影响下屈服，被腐化为魔物。

# 月相周期与时间

- 朔望月（Synodic Month）：从新月到下一个新月，平均29天12小时44分2.9秒。
- 恒星月（Sidereal Month）：月球绕乐园星公转的真正周期（以恒星为参照），约27.3天。
- 月相变化速度：每日月面被照亮区域变化约12.2°。

# 月相的影响与意义

新月代表新开始，满月象征结果或情绪高涨。一些重要的仪式往往和月相高度绑定。

月相象征阴晴圆缺，寄托团圆（如中秋节）、离别之情。一些节日传说也与月相关联。

满月和新月时，太阳与月球引力叠加，引发大潮；上弦月和下弦月时引力抵消，形成小潮。

部分传统农业根据月相播种或收割（如“月下种菜”习俗）。

月兔文明拥有特殊的文化传统，与地上人不同。月面大结界下的环境与在外部观测到的月面环境大相径庭，但当外部施加的影响足够大时，也会影响到结界内的月兔之城。

绒花帝国以朔日为每月初一，望日为十五或十六，通过闰月调和季节。详见[[绒花帝国的历法|历法]]。
