传统的军事编制思维在广袤而残酷的太空环境中需要革新。历时数年，圣卫军打造了一套从单兵到舰队的完整体系，它不仅包含人数，更深入探讨了其背后的组织逻辑、战术思想与文化内核，是绒花帝国军事理论的核心部分。

# 陆军编制

在幻境中，行星军（陆军）负责行星级别战役。圣卫军的核心任务是控制关键航道、星门、空间站与资源星球，而非广袤的无人深空。 **行星环境与舰船接舷战**是行星军通常需要面对的场景，因此行星军在登陆和控制任务中是最接近传统陆战的。但由于行星级别目标的复杂性，往往需要海陆空联合作战。行星尺度下的海陆空装备均已整合到同一个系统中，便于行星军在复杂多样的环境下作战。有时行星军也需要攻打或防守太空建筑（要塞、城市、科研站、工厂等）。

机动能力、AI、武器和生命维持系统的水平，直接决定了最小作战单元的规模与能力。由于通讯延迟（甚至断绝）和环境的极端多样性，小单位必须具备独立生存、决策和完成战略任务的能力。战场上，每一名士兵都不是孤立的，他们与AI、无人机、机甲和星舰系统深度融合。

行星军的编制体系以人类为主体设计，由于幻境人口稀少，缺乏人力，往往需要机器人单位来填充编制空缺。因此人类与机器人混编是常见的操作。实际中，人类往往担任“长官”，作为较小编制单位的指挥节点。而机器人士兵则负责基层作战任务，冒着更大的风险。从而减少有机人口的伤亡，保存有生力量。这是经过实战检验的、当下最合适的作战思路，对幻境的陆军编制有深远的影响。

下表提供了基础信息速览，之后我们会详细介绍每一级别的设计思路。其中“同级编制”指的是该级别下的异名编制规模，通常是规模较小的版本，但在指挥时视为同一级。

- 班 / 5 / 无 / 不可继续分割的最小的战术单元
- 排 / 15 / 无 / 3个班
- 连 / 50 / 无 / 3个排，首个排增加5人
- 营 / 100 / 无 / 2个连
- 团 / 1000 / 无 / 10个营
- 师 / 10000 / 旅 / 必须编入至少一个连级单位
- 军 / 10000以上 / 无 / 必须编入至少一个师级单位

目前行星军的编制体系为**军、师、团、营、连、排、班**。旅作为师的同级编制，通常拥有更少的人数，可以看作**轻型师**。但在指挥系统中，仍属于师级，拥有师级权限。满编的团包含10个营，一个旅通常配备不超过6个团。师可以编入额外的支援单位，包括支援连和支援营。可选的有：后勤连、医疗连、工兵连、侦察营、火炮支援营、空天支援营等。对于支援单位的数量并无过多限制。支援单位可以带来多种增益，如增强医疗力量、减少装备损失、提高装备可靠性、提供额外的侦察力量、提供额外的火力等待。在编辑时可以按需选择。支援单位是非强制要求配备的。几乎所有支援单位都可以通过师属飞船空投至作战地点（只要空投可用）。

由于战术组成不同，师级单位下编入的兵力数量有很大差异。如一个师可以编入3个坦克连、3个步兵营、3个空天团；也可以编入6个机械化步兵团、2个自行火炮团、4个重型装甲连。因此师级编制的人数变化很大，在数十人到上万人不等。但由于**必须编入至少一个连级单位**的设定，加上师属支援单位，人数必然在50人以上，**通常不低于300人**。

目前圣卫军以师级作为核心指挥单位。若干个师组成一个军（集团军），根据战略需要幻境中会设有若干个军，分布于不同的战区。师可以部署于舰队，跟随舰船在不同星系间移动（战舰设计之初就考虑到了大量运载人员的需求，不需要额外建造运输船）。实战中舰队作为太空战的机动火力平台，也能为行星军提供驻扎基地。

## 定位

- 班：基本的机动与居住单位，通常共用一个生活舱或运输舱。能执行复杂的多方向战术配合。在战斗中作为“战斗小组”行动，分工明确。是推进战线的基石。
- 排：微型战术单位，负责占领、守卫和近距离突击。
- 连：与学校中一个班级的人数相当。彼此之间互相认识，关系密切。成员间通过神经链接共享感官，装备动力机甲，能够完成小型据点的防守任务。每个连的首个排增加5人，称为“加强排”，这5人通常是额外的支援人员，负责辅助3个排的生活与战斗。
- 营：机动性强、灵活的小型战术单位。具备多兵种协同作战能力，对军事科技显著落后的目标能够发动强力的打击。
- 团：拥有一定体量的战术单位，具备持续作战能力。可以独立攻占小型太空据点，执行低危的局部任务。自主性强，能独立守卫一个前哨站、空间站模块或负责一艘大型舰船的内部安全。有时从师或旅中拆分重组“独立团”，拥有比普通团更大的编制（3000-8000人），作为准师级单位分配任务。能发动一场行星级别的局部战役，或全面接管一个中型殖民地。
- 师、旅：永久性的行政与作战编制，通常以其驻守的要塞或星舰命名，拥有深厚的团队荣誉和历史传统。通常拥有专属的徽章，作为独特的标识。便于机动和部署的核心指挥单位。在烈度较高的战役中，往往需要数十个师全力押上。

## 不同时期的陆军编制变化

早期由于兵员严重不足，人数往往存在严重缩水。如一个师仅有2000人，至多5000人。一个师下仅有数个连。在[[大玥帝国]]初期也存在这一现象，一直持续到[[末日灾变]]前。而[[月兔之城（城邦）|月兔之城]]则因兵员充足不存在此现象，鼎盛时期甚至维持着一百万大军。目前幻境普遍利用机器人士兵充人数，实际上的有机人口只占一小部分。

# 太空军编制

太空舰队是绒花帝国的矛与盾，其编制完全围绕星舰的功能与协同设计。战舰即基地，行星军与太空军并非泾渭分明，舰船通常也是行星军的指挥中心和前进基地，太空军更多的是负责舰船本身的运作。行星军和太空军不存在上下级关系，而是不同军种。

由于目前的大多新锐型号仅需数十人便足以维持运作，单舰所需的水手数量极大减少。

## 单舰单位

人数视舰船级别而定。由于幻境舰船已高度自动化，舰船本身不需要太多水手来维护和操控，可搭载大量的行星军。以下人数仅供参考，实际上大部分人员都**由机器人代替**，有机人口仅占很小一部分。节约下来的生活物资和船员宿舍可用于供养更多陆军士兵，便于大量士兵搭乘飞船长途行军。

* 突击艇、侦察机：1-2人（驾驶员、武器官）
* 护卫舰：50-80人
* 驱逐舰：150-300人
* 巡洋舰：500-800人
* 战列舰：1200-2000人
* 神武舰：3000-5000人（不含海军陆战队）

定位：最基本的太空作战平台。舰长拥有极高的自主决断权。若为师级单位直属的母舰，则**师长兼任舰长**。稍大的飞船会配备海军陆战队（隶属于舰队的机器人士兵），在缺乏陆军支援的情况下进行星球登陆作战或防守太空据点。

## 巡逻舰队

- 数量：3-6艘舰船
- 典型构成：1艘巡洋舰（指挥舰），2-4艘驱逐舰或护卫舰，1艘支援舰（补给、维修）。
- 定位：高机动性的快速反应部队，用于巡逻、侦察、护航和突袭。是深海（深空）中的“猎人”。

## 战术舰队

- 数量：12-20艘舰船
- 典型构成：1-2艘战列舰或神武舰（核心），4-6艘巡洋舰，8-12艘驱逐舰/护卫舰，2-3艘支援舰（补给、维修、医疗）。
- 总人数：约8000 - 15000人
- 定位：舰队决战的主力。能独立执行一场中等规模的战役，如夺取一个恒星系的控制权。通常拥有一艘旗舰作为机动指挥中心。

## 战略舰队

- 数量：60-100艘以上舰船
- 典型构成：多个战术舰队组成的混合编组，包含所有舰种，并配有大量移动船坞和建造船等支援单位。
- 总人数：50000 - 100000人以上
- 定位：帝国的核心军事力量，通常镇守关键星域或执行大规模征服计划。其动向直接关系国运。

# 特殊战斗人员

## 特战干员

- 编制：来自**荣安堂**的惩戒部，作为特殊军事单位独立于常规军队，以“攻坚小组”（5-7人）为单位行动。
- 作用：荣安堂培养的精英，他们可以是能感知超空间的“导航员”、通过精神力干扰敌方电子设备的“灵能黑客”、或合法直接操作魔法的“战斗巫师”。他们是珍贵的战略资源，有时能扭转战局。
- 备注：归属于荣安堂，不接受圣卫军的指挥。

在战斗开始前数小时，网络战就已打响。他们负责瘫痪敌方的指挥链、制造虚拟幻象、甚至策反敌军的AI副官。他们放弃大舰队编制，采用由一艘母舰指挥大量小型、无人、高机动性攻击单位的“蜂群”战术。这能极大降低人员伤亡，并让敌人防不胜防。

## 明镜军

- 编制：来自**明镜军**，平时没有固定的队伍划分，战时可以灵活组建数人至数十人的战术单位。
- 作用：幻境的禁卫军，负责乐园星要地的防御。
- 备注：归属于明镜军，不接受圣卫军的指挥。

明镜军中最精锐的死士被称为[[花之骑士]]，拥有十分强大的实力。
