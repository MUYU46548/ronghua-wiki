# 种族介绍

- 种族名称：仙灵
- 别名：精灵
- 多样性：高
- 代表角色：魏耀辰

某些情况下，他们也被称为“精灵”，但需注意避免与[[妖精]]混淆。通常而言应使用标准名称。

仙灵是一类飘逸而灵动的存在，介于物质与能量之间。他们大多对人类较为友好，个别仙灵可以拥有人形。仙灵与自然界的联系较为密切，常出没于山林、溪谷、云端等远离尘世之地。

# 生理特征

- 形态：通常呈现为半透明或发光的灵体形态，部分仙灵可凝聚为类似于人的外形。显形时通常带有飘逸、空灵的气质。
- 寿命：极为长寿，几乎永生，但并非绝对无敌——在特定条件（如灵气枯竭、封印等）下也可能消亡。
- 体征：灵光、半透明体态、飘逸的动态效果。人形仙灵通常气质超凡脱俗。
- 能力：与自然灵气相关的超感应能力、治疗与净化、幻术、飞行、元素亲和等。部分高级仙灵拥有独特的专属能力。

# 文化与习性

- 聚居形式：主要为散居。 
- 主要信仰：无。
- 文化传统： 无统一文化传统。

# 社会结构

通常无明显社会结构。

# 地理与环境适应

- 发源地：通常在自然界小概率生成。
- 主要分布：世界各地。
- 环境适应：偏好在灵气充裕的自然环境中活动，远离工业污染与世俗喧嚣。
