# 基本信息

- 生物名称：月光麋鹿
- 别名：光之鹿
- 生物类型：动物
- 主要特征：银白色虹彩皮毛，可随视角与光线变幻色泽

# 生理特征

- 外观尺寸：
	- 肩高：1.8-2.2 米（成年雄鹿略大于雌鹿）。
	- 体重：雄鹿280-320千克，雌鹿200-250千克。
    - 角：仅雄鹿有角，角干向两侧伸展，末端分叉呈掌状，表面有细微的荧光纹理，随年龄增长愈发深邃。
    - 毛皮：主色为银白色，毛干内含某种类晶体结构，能在不同角度和光线下折射出蓝、紫、粉、金等虹彩色泽，夜间则反射更为柔和的月光。
- 感官与能力：
	- 视觉：眼球后方具反光膜，弱光视力极佳，并能感知部分紫外线，用于识别同类标记与食物。
    - 听觉：耳廓大且灵活，可独立转动，能捕捉低频长波声响，提前预警远方捕食者。
    - 特殊能力：高速奔跑时，全身虹彩会产生“动态掩蔽”效应，令捕食者难以锁定其轮廓；群体奔跑时，个体光晕可产生较强致幻效应，形成移动的彩色光墙，引发捕食者的视觉眩晕或定向障碍。
- 生命周期：
	- 孕期：约8-9个月，每胎通常一仔。
    - 幼年：幼鹿毛色为淡灰色或棕色，虹彩随性成熟（约3-4岁）逐渐显现。
    - 寿命：野外寿命约18-22年，人工饲养下可达28年。

# 行为与习性

- 食性：草食性，大部分草本植物均可作为主食，有啃食树叶的记录。其消化系统能软化硬壳果核，促进种子传播。
- 活动规律：晨昏性活动为主，晴朗日间亦活跃。夜间会寻找开阔地或林间空地休息，依靠群体警戒和特殊皮毛光泽进行低光环境下的信息交流。
- 社会结构：基础单位为由一头强壮雄鹿、数头雌鹿及幼崽组成的核心家庭群（5-15头）。迁徙期多个家庭群可结成超过百头的临时大联盟，共同抵御威胁。
- 常见行为：
	- 光语通信：利用虹彩光晕的闪烁频率、色阶变化进行视觉交流。已知快速蓝闪表示警戒，金色扩散光晕代表安全。
    - 群体防御：遭遇捕食者时，家庭群会迅速聚拢，幼鹿被护在中心，雄鹿在外围。若捕食者逼近，则会启动集体冲锋，以光墙冲击瓦解对方攻击阵型。

# 分布与生态位

- 主要栖息地：
	- 核心区域：[[乐园星]]大陆东南部的稀树草原与落叶阔叶林交界地带。
    - 次要区域：大陆南部温暖湿润的丘陵地带（[[梓坂城]]以南）有少量分布，该处种群毛色可能偏浅金色，体型略小（待进一步观察确认）。

# 用途与价值

## 食用价值

月光麋鹿的肉质在乐园星被公认为顶级食材，但因其文化神圣性，通常**严禁主动猎杀取肉**。仅允许食用**人工养殖个体**。

- 鹿肉特性：肌肉纤维细腻，富含天然呈味核苷酸，自带清淡的草木甜香。经烹饪后，肉色呈浅粉至淡金色，在特定光线下可能会泛出微弱星辉，代表肉质新鲜。与传统鹿肉相比，回味偏甘，肉质嫩而不散。
- 经典做法：
    - 月光鹿肉水饺：以嫩肩肉手剁成茸，混合黑胡椒、椒盐等调味。煮成后饺子呈半透明状，内馅透出柔和的粉色，鲜甜中带有淡淡花香。这是[[绒花宫]]常见的祈福宴品。
    - 虹彩鹿肉干：取优质后腿肉，切条后用香料与料酒腌制，熏烤风干。成品表面因蛋白结晶，会呈现彩虹色纹路，耐储存，是长途旅行者与护林队的高能口粮。

## 药用价值

现代药学发现月光麋鹿全身各部位含有独特的活性成分，具有显著的药用潜力。

- 鹿角精华（茸）：每年春季自然脱落的鹿角（带有茸毛的基部）是珍贵药材。
        - 功效：疗愈创伤、强筋健骨；尤其对运动损伤有显著缓解作用。
- 鹿血：以特殊手段采集的血液。
        - 功效：制成安神口服液，可有效改善焦虑、失眠，修复中枢神经损伤。因其能促进褪黑素自然分泌，服用后常伴有温暖柔和的睡眠体验。
- 鹿胎与胎盘：用于制备抗衰老药膏，可延缓皮肤老化，促进胶原蛋白再生。由于绒花帝国医疗科技高度发达，且绒花人自带永生属性，该功效无应用前景，在此权作记录。

## 魔法素材价值

在某些魔法流派中，月光麋鹿的身体部位是天然的高品质魔法媒介，尤其适合幻术、光系及精神类法术。

- 鹿角粉末：将自然脱落的鹿角研磨成极细粉，可作为某种幻术墨水的核心基质。书写在符纸或法阵上，可增幅“迷魅”、“隐形”及“诱导”类法术的精准度与持续时间。高级施法者会将其添入法杖顶端，使施法时产生虹彩流光，干扰敌方施法锁定。
- 虹彩皮毛：整张自然脱落的毛皮，经灵能附魔后，可制成“幻影斗篷”，穿戴者能主动激发皮毛中的光子晶体，扭曲周身光线，实现类似光学隐形的效果。但每次使用后需重新充能。
- 鹿泪与唾液：传说月光麋鹿在满月下流淌的泪水，是制作“真实视域药水”的关键引子，能让人看破低级幻象；其唾液则可用于制作“解毒灵膏”，对多种植物性毒素有奇效。

# 其他资料

- 研究争议：关于南部少量种群的分类地位，目前学界存在争议。部分生物学家认为其应为月光麋鹿的南境亚种，而非同一物种。该假说若被证实，将丰富对乐园星物种辐射演化的认知。
- 保护现状：当前保护政策下，整体种群数量稳定，但偶尔有非法偷猎者觊觎其珍贵的毛皮与鹿角，安巡司已针对此问题增派巡护力量。
