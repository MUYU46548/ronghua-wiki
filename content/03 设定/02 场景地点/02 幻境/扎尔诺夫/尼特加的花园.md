# 概述

- 名称：尼特加的花园
- 英文名：
- 别名：无
- 类别：花园
- 所在地：第一临时庇护星球

[[尼特加]]经营的种植区，目前为公益拓荒行动中的一处自然改造区域。

# 结构设定

- 花园规模：占地很大，远超单靠人力可轻易打理的范围。荒草齐膝，只有几条被人踩实的小路弯曲穿过其间。
- 植被特征：除荒草外，有刺槐（约两三楼高，为长椅提供荫蔽）；尼特加正在此种植树苗，共种了三棵（前两棵分别干死和风折）。
- 设施：花园门口有长椅，长椅旁种有刺槐。附近有圣卫军巡逻飞船经过，有农业机器人和机器人士兵在活动。
- 氛围特征：开阔、荒芜但蕴含生机。

# 相关角色

- [[尼特加]]：被提前释放后，他开垦土地、搭建房屋，种植作物。他曾在此种树并偶遇哈伦。
- [[哈伦·苏尔登·兰开斯特]]：由**维克多**带至此处，与尼特加相遇交谈。
- 维克多：将哈伦带至花园门口后离开，未进入。
