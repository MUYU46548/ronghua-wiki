# 概述

- 名称：风云线
- 英文名：Fengyun Line
- 别名：风云地下铁路
- 类别：地下铁路
- 所在地：连接风神城和丰竹

风云线于2025年5月3日正式开通，是一条横跨柔光海峡的海底地铁。该线路起始于[[风神城]]观澜枢纽站，终止于庆云岛丰竹站。在观澜枢纽站可换乘[[青鸢线]]。

当运行稳定后，车次有所增加，并增设了一条同方向的货运专线（利用预设通道快速部署）。

# 结构设定

列车结构大体与青鸢线列车相似。

>当车身完全进入海底隧道时，车厢顶部的蓝色环形灯带骤然亮起，宛如一条漂浮于空中的银河。透过车载电视播放的景观展示，乘客们惊喜地看到，隧道上层的海洋生态信息通过实时演算被转化为影像——蓝色水母群随着列车的行进节奏翩翩起舞，多彩的鱼群在岩壁间自由游弋，甚至连海水因气压挤压产生的细微“咕噜”声都似乎清晰可闻。
>
>——《蓝月之声》26.庆云岛海底地铁正式开放（2025年5月3日）

采取客货联运模式，车厢分为客舱与货舱。除青鸢线列车的常规配置外，新增餐车车厢。乘客被允许在餐车车厢内进行饮食。青鸢线也将陆续升级餐车车厢，提供车上餐饮服务。

隧道的防护系统可以抵抗海水的水压和地震，不会轻易崩塌。
