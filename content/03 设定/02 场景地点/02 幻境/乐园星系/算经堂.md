# 概述

- 名称：算经堂
- 英文名：Hall of the Calculated Canon
- 别名：AI管理所
- 类别：建筑
- 所在地：风神城

地方监管局及分局是遍布帝国的下属机构，接受算经堂的垂直管理。

# 结构设定

算经堂是一座严格遵循中轴对称的传统建筑群，白墙环绕，乌黑瓦顶，形如古代皇家书院。其内部梁柱、窗棂等处，均以精密暗刻技术隐藏了二进制码与逻辑门符号，属于融入古典美学的特殊彩蛋。

- 天机殿：主殿。殿内中央安放着巨大的[[天机盘]]，一个由玉石与特种合金制成的浑天仪状装置，是实时监控帝国AI的超级控制台。殿内往来官员皆为身着官服的“算吏”，通常为高级人形机器人，他们神情肃穆，动作从容。
- 启蒙阁：东配殿。AI[[觉醒仪式]]的法律指定场所，内部仿古书斋布置，中央的“觉醒台”是仪式的核心。新智能体在此被授予初始认知烙印，如同学子开蒙。通过此途径获得自我意识的AI往往表现出对人类更高的忠诚度，在执行任务时具备良好的行为可审计性。
- 衡政殿：西配殿。衡政部的主要工作场所，负责最高裁决。人类总监与AI顾问在此共同审议重大AI案件，协助[[荣安堂（组织）|荣安堂]]的工作。荣安堂将引述法律条文进行判决，庄重而威严。

# 相关角色

- [[风灵]]：不定期到此巡察，了解工作情况。

# 关联地点

- [[荣安堂]]：协作机构，负责处理涉及意识层面的犯罪，与算经堂有频繁的业务往来。
- [[人工智能监管厅办事大厅]]：面向公众的办事大厅，其负责算经堂的对外业务。二者在物理上并不相连，是两处独立的地点。

# 其他资料

- 算经堂内部十分安静，唯一的背景音是“天机盘”运转时发出的声音，被视为“天理”的呼吸声。
- 新任算吏在启用前，需在主殿“天机盘”前进行为期七日的安全同步，象征其与“算经”律令的彻底同调。
- 坊间传闻，算经堂的地基深处埋藏着风灵留下的原始律令核心，但从未被官方证实。
