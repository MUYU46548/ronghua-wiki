# 概述

- 名称：梓坂城
- 英文名：
- 别名：
- 类别：
- 所在地：

梓坂城是乐园星的主要城市。作为幻境早期就已存在的定居点，梓坂城拥有比[[风神城]]更加悠久的历史。梓坂城在**废弃城市**上改建而来，经过数年的建设便十分繁荣。

# 结构设定

- 设有风神庙。
- 有传统店铺、餐馆、戏台等。
- 街道上没有盲道，因绒花帝国医疗科技可治愈大多数身体障碍。

# 相关角色

- [[暮雨]]：经常来到此地，曾在此接受烛火治疗。
- [[风灵]]：常和暮雨一同来到此地。
- [[魏耀辰]]：曾在城中风神庙为暮雨主持治疗，用烛火为他减轻苦痛。
- [[初云]]：常来此地处理政务，有时会负责主持活动仪式。
- [[梦琴]]：有时会来此地游玩。
- [[陈彩燕]]：从粘土世界迁徙到幻境后，居住在这座城市中。
- 特里贝纳：厨师，被梦琴在此招揽。

# 关联地点

- [[风神城]]：隔江相望，两城之间由公路与地铁联通。
- [[青鸢线]]：链接风神城与梓坂城的地下铁路，部分技术来源于月兔文明。
