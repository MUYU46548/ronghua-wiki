# 概述

- 名称：望凤山
- 英文名：
- 别名：
- 类别：
- 所在地：风神城西南部

位于风神城西南方向的自然风景区，包括森林、山地、湿地等多种地形，面积辽阔。[[复仇神殿]]遗址所在地，[[羽落之战]]发生地。

# 结构设定

- 山顶建有花海，由机器人每日照料.
- 山脚设有[[德斯特文明博物馆]]，展出玥国文物
- 博物馆附近有纪念碑，刻有“永久禁止复仇”字样。
- 山下有小饭馆，现已发展为游客常去的餐饮点。

# 相关角色

- [[暮雨]]：曾在此参与羽落之战。偶尔与风灵来此游览。
- [[池鸿威]]：曾在此宣布圣君更易，将力量传递给暮雨。
- [[风灵]]：曾在此见证池鸿威的最后辉煌。
