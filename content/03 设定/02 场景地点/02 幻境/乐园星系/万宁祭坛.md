# 概述

- 名称：万宁祭坛
- 英文名：Wanning Altar Square
- 别名：创世祭坛、祭坛广场
- 类别：建筑（祭坛）
- 所在地：神殿大街西侧

万宁祭坛位于神殿大街西侧，正对着[[绒花宫]]的西大门（原正门）。

由于暮雨受认知滤镜影响，过去暮雨曾错误地以为，万宁祭坛是纪念暮雨创造了幻境而建造的。事实上只是幻境中一处普通的石头平台。

# 结构设定

- 广场外围立有带纵向凹槽的石柱，基座刻有回字纹。
- 用于大型典礼、阅兵、节日文艺表演等，平时则是普通的公园，供居民随意参观。

# 相关角色

- [[风灵]]：常在祭坛举行仪式。
- [[暮雨]]：常在祭坛举行仪式，曾在此与风灵一同迎接梦琴。
- [[梦琴]]：被风灵和暮雨召唤至此，在得到祝福后成为了绒花人，拥有不朽的少女形体。

# 关联地点

- [[绒花宫]]：位于万宁祭坛东侧，可通过地下通道过街。

# 其他资料
