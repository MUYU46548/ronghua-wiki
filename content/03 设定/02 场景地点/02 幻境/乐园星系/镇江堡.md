# 概述

- 名称：镇江堡
- 英文名：Zhenjiang Castle
- 别名：无
- 类别：建筑（城堡）
- 所在地：神殿大街西南处

位于神殿大街西南处的大城堡，据守着横跨[[木棉江]]北支的大桥，因此得名镇江堡。镇江堡是[[风灵]]在三岁生日收到的生日礼物，由[[暮雨]]建造。该城堡在早期具有一定的防卫功能，后成为乐园星重要的驻军基地。平时有许多机器人在这里驻扎。城堡地下的宝库也存放着许多风灵的财宝。

城堡的外观是类似西欧石头城堡的设定，科技水平为中世纪后期。因此缺乏防御火器的特化结构，对炮兵的防御能力较差。象征意义远大于实际战斗数据。但该城堡为圣卫军提供了驻军地点，一定程度上可以加强[[绒花宫]]和[[风神府]]的防卫。该城堡配备了一定的防空武器和远程打击武器，可以进行远程精确制导攻击。城堡周围没有农场，并不能像传统城堡那样发挥“城”的功能。但是城堡的仓库中存储了大量补给品，很好地弥补了这一缺陷。

# 结构设定

城堡西南方有一条横跨江面的大桥，可以令重型车辆通过。

城堡中有一个很大的宴会厅，风灵等人偶尔会在这里举办宴会。

城堡地下有一个巨大的宝库，里面装满了财宝，是风灵的秘密藏宝库。藏品不限于黄金。宝库有好几层厚重的防爆门保护，某些情况下也可以当作防空洞。

城堡的大部分空间是存放武器的地方。有许多圣卫军士兵驻扎在这里。远处的草地底下还隐藏着许多重武器。机器人士兵们在此全天候巡逻，戒备森严。空中有无人
