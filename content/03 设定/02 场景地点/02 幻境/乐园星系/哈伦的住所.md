# 概述

- 名称：哈伦的住所
- 英文名：
- 别名：无
- 类别：建筑（府邸）
- 所在地：风神城

哈伦的住所位于[[风神城]]，[[哈伦·苏尔登·兰开斯特]]居住于此。

# 结构设定

- 布局：包含至少一间客厅、一间书房、一间厨房、两间卧室。窗外可见风神城的风景。
- 陈设特点：
	- 拥有至少一个书桌。
	- 有书架，[[白芝原]]原入住后将书籍重新排序。
- 改造痕迹：哈伦曾为白芝原整理出一间小卧室，作为其居住空间。

# 相关角色

- [[哈伦·苏尔登·兰开斯特]]：住户，这间房子的主人。
- [[白芝原]]：被哈伦带至此处居住，在此完成自我认知挣扎、试图格式化记忆、最终离开。
- 三位机器人警卫：安巡司警卫，在此处对哈伦执行逮捕，并宣读拘捕令。

# 其他资料

- 关键事件序列：
    - 1月5日：哈伦在此整理申请材料，装满牛皮纸袋。
    - 1月7日：在此阅读《意识体的法律边界》，回忆与[[叶绫]]的最后对话。
    - 2月22日：带白芝原返回此处居住。
    - 3月15日：凌晨3点，白芝原试图用平板格式化自身数据，哈伦阻止。
    - 3月18日：白芝原离开，后短暂返回等待哈伦。
    - 4月13日清晨：哈伦在此被安巡司逮捕。
- 窗外景观：可见风神城街道夜景与飞船航线，山顶有零星灯光。
- 饮食细节：厨房有水槽，哈伦曾给自己倒水喝；外卖鸭腿饭曾被送来，白芝原拒绝食用，并声称叶绫讨厌鸭腿。
