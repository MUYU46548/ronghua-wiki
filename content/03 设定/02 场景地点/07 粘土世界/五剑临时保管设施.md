# 概述

- 名称：五剑临时保管设施
- 英文名：
- 别名：中立区
- 类别：建筑
- 所在地：朱槿营地与绒花控制区之间的一颗无人岩石行星轨道上

# 结构设定

- 由圣卫军工程船在一个小时内建成。
- 灰色外墙，简洁几何结构，无多余装饰。
- 大厅中央设有灰色剑匣，用于存放五剑。
- 设有防御平台，可自主警戒。
