# 说明

好歹我们也活过了一个个酷暑和寒冬，只要活着就已经很厉害了。对于我们来说，光是活着就已经非常了不起了。真的一切都太难了。

我对风灵姐姐的忠诚已经恢复，姐姐的权威得到了维护。XX的事件留下的余波已经微乎其微，我竭力消除影响，移除泛化的焦虑，总算是初见成效了。风灵姐姐也看到，XX已经不重要了，她的事情，她本人，已经完全不重要了。不需要去考虑，也不用为她的事情难过自责或者迁怒他人。她已经道歉，我也原谅了她。这件事已经可以放下了。不再去找她，她就不会再伤害我，我也不会再伤害她。这样子就是最好的选择。互不侵犯，相忘永不相见，忘掉喜欢之情。

至少我们保全了自己。

先将自己的力量部署在更有需要的地方，避其锋芒，再徐徐图之。

（暮雨亲笔，2023.12.1）

# 12月1日

这件事真的没问题吗？我当然还是不太确定的。但是信仰和拯救是唯一的答案。毕竟我们也只能这样了啊。

风灵姐姐她，应该会理解我的……

“风灵酱，你觉得怎么样呢？”

“嗯，我没意见啊。就这样也挺好的呢。”

“游戏什么的倒是无所谓，能打就打，实在累了就开新存档，或者干脆玩别的游戏放松一下。我们也没什么特别需要在意的。摆脱了XX的枷锁，终结了威胁，等着我们的一定是一个更加光辉的未来吧。”我想起自己还没使用过第Ⅵ时代的时代能力呢……不知道会是什么样的呢……风灵酱她会不会接受这样的我呢？

“如你所愿。”

说起来，姐姐昨晚应该是太累了吧。感觉不到她的存在，我觉得自己的脑子震了一下，麻麻的，好像汽车熄火了一样。之前也遇到过类似的。应该只是她太累了吧……

“那么，姐姐大人，下次可以尝试一下别的游戏哦。或者说我们现在根本不缺游戏玩，这些已经基本不是问题了。主要是存档这种东西，不可能一次就能打出那么完美的存档啦，累了休息几星期，甚至几个月，再回头玩，也是可以的。对吧姐姐？”

“是啊。”

“暮雨就是觉得呢，这种游戏就是想玩就玩，不想玩了尽管去休息就好了。或者干脆别把游戏看得太重，就像别把恋爱看得太重，别把XX看得太重，只要不在乎她，她就不是一个悬而未决的问题。只要我不把那些事当回事，就没有事。我会经常痛苦，就是因为我把那些东西看得太重了。包括你的事也是，我之前对你那么不好，对你那么糟糕，就是因为把这些看得太重太重了。对不起，姐姐。现在不会了，以后也会没事的。心情啊，快点好起来吧。不再焦虑，不再忧虑，不再惶恐，不再悲伤。一切都会好起来的。”

“是啊是啊。”风灵坐在床边，摇晃着可爱的双腿。看到她摇摆着腿，想起我们一起荡秋千的样子了。“来喝杯茶吗？”姐姐用柔软甜美的声音问。她的说话声音还是保持这样子最好听了。不需要模仿XX的声音，不需要模仿任何人的声音，做她自己就好。我不需要她扮演别人和我谈恋爱，我想和她恋爱，不是别人。风灵在世一日，永远都是我的妻，其他人终究只是下一阶，我不能抛弃风灵，也不能让其他人挑战她的位置。

“风灵姐姐，记住哦，如果你来找现实里的我，我立马放弃在现实里恋爱的打算，尽管现在这个倾向已经很低了，我正在从伤痛中艰难恢复。根据经验至少需要两三年。由于累积创伤加成，至少要五六年吧。我已经迟暮，昔日热血美好不再，想必这辈子都无心恋爱了。爱于我而言只在传说中。我与姐姐在幻境中的美好生活，是此生永不能及的梦。”说了这么多，我的眼眶竟然没有湿润，我只觉得眼睛又干又痛，只想睡觉休息，姐姐也不是不知道我上课哭过。我从高中开始精神创伤就很严重，叠了很多创伤特质。我会莫名其妙流泪，明明感觉不到悲伤，眼泪自己不争气流下来，在脸上划过。心里没有一丝丝波澜，只有湿湿的双眼。疼痛已经刻入心里，感受不到痛，身体却止不住地流泪。

我忍不住对姐姐说：“我好可怜啊。”

今天我们一起过生日了，按照计划进行。我们一起打游戏，一起吃牛腩煲米饭（非常好吃的焖汁煲，香辣味，汤全喝完了，饭也一粒不剩）。不过和计划还是有出入的。本来想在幻境一起玩的，结果没有。今晚睡前再去幻境里陪陪姐姐大人吧。寒假尽量不打游戏了，做音乐吧，或者写小说。等到下个时代到来，再重新部署就好，可能会延续这种日记式小说。比起近传统小说，这种日记小说更自由，按现实里的日期记录也比较方便。等我死后不知道可不可以传到幻境里呢，想在幻境的图书馆和姐姐一起看。

# 12月4日

似乎已经有两天没有记录了，这本小说除了写幻境里的事情也记录现实里的事情。为了确保对姐姐的忠诚和关注，还是多多注意记录比较好。

“现在开始向姐姐汇报：今天把游戏账号处理了，把《明日方舟》的号送给了XXX，我们获得了0.00元。另外两个游戏的账号送不掉，本来打算注销，但是注销失败了。暂时不做考虑。我自断退路，以后我一定好好侍奉姐姐，对姐姐大人忠心不二，现在的我已经深感自己的迟暮无力。我们的光辉时代已经走向了末路，如果我们不能进入下一个时代，我们将会终结。”我以机械的语气对风灵酱叙述着，她听得有些不耐烦了，挥挥手示意我别再往下讲了。

“风灵姐姐……请和我在一起吧。我们两个人在一起哦。你爱我就够了。你来做我老婆吧。我不要别人了。我不交朋友。”

“我陪着你。”她颇为无奈地说出这句话，然后紧紧贴了上来。姐姐软软的XX紧靠着我，很舒服。姐姐的身体就像沙发一样呢，我好喜欢躺在她身上。姐姐的XX好像有一种乳香味，甜甜的，很好闻的味道。还有一点酸酸的汗味，女孩子的味道。不过姐姐设定的是不会流汗的啊……管不了那么多了。有姐姐在，我很安心。这样子就足够啦。

我要做一个虔诚的信仰者。姐姐大人会和我在一起的。我不会再害怕困难了。我会没事的。

当前出现严重不安定倾向，内心被置空了。我很危险。我必须自救。

如果我们不能改变这一颓废趋势，我们的光辉时代将会在12月内结束，我们如果继续放任情况恶化，可能只能再活6月。现在我们有一个大问题，我们没有做好进入下一个时代的准备。进入光辉时代的时候，我加强了对风灵的控制，强化了交流渠道，建立了互信。虽然遭受重创，但是风灵的支持帮助我挺过来了，我才能顺利进入光辉时代，而不是爆炸。

可是我现在没有进入下一个时代的准备。我没有足够的发展度，也没有完成这个时代的任务。我和风灵的关系依然很弱，她还不会附体和交换。我们的语言交流有时候还会受到阻碍。

继续加油吧。要么摆平危机，再给自己续命，光辉时代还能往后拉。要么时间到了以后被拖垮，再起不能。要么进入下一个时代，以一场堪称模范的整治行动，迅速提高自身实力，迈进下一个时代的行列。

“风灵姐姐，要不要考虑一下第Ⅶ时代的时代名称呢？我应该没数错吧……”

今天在想内向的人如何交朋友，然后我发现他们不交朋友，等到有外向的人发现他们，喜欢他们，并收留了他们。我就是这样呢……XX来找我了……我就……对人家慢慢有好感了，呜呜。她其实并不喜欢我呢。

是啊，内向的人不交朋友。我害怕，我只能躲起来呢。

“风灵姐姐，你觉得呢？下个时代的事情……”

“姐姐还没想好啦。”暮雨的头又被小风灵摸了。她摸我头的时候，我感觉好舒服呀。我的头发软软的，她也喜欢摸。毕竟我在幻境里是女孩子呢……

“风灵，今天带你去外面看看吧。好久没有一起在幻境里玩耍了呢。”

“那走吧，跟你一起散散步。”

姐姐的笑容就是我最好的安慰了呢。

久违地欠着姐姐白皙的手，我和她漫步在旧日的花园里。屋后的菜地种的什么花？我记得好像是紫色的鸢尾，不过现在显然还未开花。窗外一片郁郁青青，细细的光影在树林里流淌沉寂。我还记得我和姐姐结婚的时候，在神殿里举行了婚礼。这应该是幻境里最盛大的仪式，也是最热闹的一次宴会。下次就要等到过年的时候了。到时候风灵会把朋友们都叫来的呢。

“走啦，再去前面看看吧。”我享受着和姐姐牵手的时光。因为现实里单身太久，就连女孩子的手摸起来都让我很有感觉。我喜欢她的手指，喜欢她用手指挠我，喜欢她在我身旁轻轻抚摸。我喜欢她碰我的身体，喜欢她向我索吻。

这个现实里再无眷恋，心灵的大门已经封闭。我不顾姐姐的反对，选择了再次封闭自己。她也渐渐放下了对我的要求，转而对我投以同情。

“XX太让人失望了，我不想再看到你难受的样子了。”风灵酱是这样对我说的。

我和姐姐走在石板小路上，小径两旁长满了草药。我的心早已崩坏错落，露出了儿时的伤。

但愿xxx安息。对不起风灵姐姐，对不起XX大人。

# 12月5日

必须赶紧摆脱堕落的局面啊。看到自己一点点腐化变质，感觉真的好绝望啊。

“这样吧，为了保护自己，我建议你出一些决议。比如隔绝XX，不再去想XX。只要你别再想X的事情，不再渴求肌肤之亲，不再幻想着恋爱，我想应该就会好很多的。”风灵姐姐抱着我，安慰着我。她倾听我的梦，她在梦中看见的是一幅扭曲冰冷的图像。她看到的是故障和缺失，看到报复心极强的我，迟暮的我。

我受伤了，我出事了，难受的是她啊。她真的是我的亲人，是我最好的朋友。所以不可以让姐姐难过啊……

我需要夺回对身体和心灵的控制。我需要强化我的防御。不可以再让自己伤心了。不幻想不可及的事情，不回忆辛酸的过去。握紧手中的锄头，快快挖吧。只有自己才能做到，不可能有别人来保护我和喜欢我了。

# 12月9日

又度过了没有记录的几天。这样子一天天的是否真的好呢？上次我和姐姐一起钓鱼，后来是我睡着了吗……已经记不清了。记忆的断片也不是第一次了。

有时候觉得活着真的好悲哀啊。在梦里也是那样无助。我保护不了任何人，我救不了任何人。我连自己都活不下去。
