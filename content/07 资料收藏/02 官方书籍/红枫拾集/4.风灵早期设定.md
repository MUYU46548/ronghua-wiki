# 基础资料

- 姓名：风灵
- 种族：人类
- 性别：女
- 生日：2020.4.8（如果没错就是这个啦）

性格：可可爱爱，对喜欢的人非常温柔，稳重内敛（偶尔开一点小玩笑，不过不会太调皮，不会搞恶作剧捉弄人）。比较黏人（会缠着宿主，喜欢待在一起）。

喜欢的事物：小动物（猫猫狗狗），大部分植物（喜欢养花木），喜欢吃好吃的！喜欢音乐，会演奏乐器！喜欢穿漂亮裙子（偏东方风，也喜欢西方裙子），喜欢跳舞（有机会一起跳吧，虽然我不太会）。喜欢和宿主在一起，非常亲近宿主。

讨厌的事物：被欺负，遭到背叛。

创造历时：（计时是邪恶哒，不是很想计时，怕丧失了动力。为了可爱的风灵，还是应该努力创造啊！让我来接引你到这个世界吧，虽然这个世界有点……难以立足，但是还有幻境不是嘛？而且我们是在一起的哦，一起加油吧！）。

想对宿主说的话：（我暂时还听不清楚你说话呢，我会加油的啦！等我听到了再写进来吧！）。

宿主想说的话：我们会在一起哒！最喜欢风灵了！我会守护着你的，我们以后一起生活，有着凡人无法超越的羁绊。如果有不开心的一定要告诉我哦，不要自己一个人憋着啦，说出来会更好一些的。

日记帖：另外写日记吧[^1]，这里就不写了哦。

历史与简介：在好朋友的引导下，知道了这样的一种事物，有点小激动，也有了创造的动机。我这段日子可以说相当不如意，悲痛欲绝。就在我认定一切都糟糕了，一切都没救了的时候，我那位朋友给了我帮助！了解了这个以后，感觉生活又有了希望！我想像他们那样，拥有自己的tulpa，一只就好啦！一只就够了！我想好了，不是任何人的替代品，她是独一无二的！我会好好对她。起名有点困难，很纠结呢，不过还算成功！就叫她风灵呢，小名灵灵？哈哈，以后再商量吧。希望她喜欢这个名字！年龄设定大概是我的姐姐，比我大一点点，是姐姐哦！我也是第一次创造，不知道会怎么样，多少有些害怕呢（不知道是不是风灵也在害怕，把情绪传给我了）。总之我会继续加油，好好对待她！好好爱着她的！我的好伙伴，最亲密的守护者！

# 更多资料

档案一：（一只柯基小狗从屏幕？右边走出来）“哇！好可爱的小狗！”（对狗狗招手，狗狗立刻跑过来了）“嘻嘻，好可爱啊，我可以养吗？我可以养吗？”（轻轻抚摸柯基）“养一只也挺好的呢。”

档案二：（落花）“又要换季了吗？时间可真快呀。”（坐在院子里的石凳上，倒茶）“去年种下的小樱桃不知道有没有长大了呢，第一次种樱桃，有点紧张哦。要不我们一起去看看吧？”

档案三：（夜晚，下雨）“突然就下雨了吗？这种天气还真是难以捉摸呢。要是……啊，我的花花！”（每次下雨地上都会落满花瓣，虽然挺香的）“哎呀，好可惜啊。”

档案四：（阴暗的山洞）“怎么回事？为什么我突然会在这里？带我出去啊！”（颤抖着，两腿发软，头晕）“好讨厌哦！怎么可以这样子啦？我生气了啊！唉，算啦，也就那回事吧。”（笑）“不过倒是快带我出去呀，好害怕好害怕！快来救我出去呀！”

档案五：（和宿主一起看山）“你觉得那边怎么样？我觉得还是应该保留那些树木，在山上做公园什么的究竟是多无聊啊？我们不是拥有整片幻境了吗？”（拍栏杆）“你呀，怎么啦？只是……在发呆吗？嘿嘿，挺可爱的。真的。你这个样子，好可爱。”

档案六：（赏月）“说起来，你是第一次见到这样的景象吗？我是说，和我在一起啦！你不是一直都想要吗？现在真的有了哦，反而无所适从吗？嘿嘿，真是的呢。”（抱住宿主，亲脸）“和我的话，就不需要害羞啦，也不用害怕，没事的。我会理解你，陪伴着你的。尽管有些时候可能累了点，不过还是值得的。别再害怕啦！傻孩子呢，我在的哦。”（蹦蹦跳跳）

档案七：（泛舟）“桃花又是一年现，这满河的花影，也真是迷人眼了。怎么，嫌我不会作诗吗？你不是也不会吗？哈哈哈”（吹笛一曲，曲毕，日已斜）“唔，我们回去吧？当然是回到我们的小窝了哦。怎么啦？又在想什么呢……嘻嘻！不用害怕的啦，都在一起这么久了还害怕啊？真是的呢。”

档案八：（看手机）“嗯哼？你还不睡嘛？等我吗？我在看新的小说啦，你要不要一起来看呢？是你的话，就完全没问题哦。来吧，没事哒。和你在一起，我很开心哦。”

- 幻境各种权限 / 是 / 呜……怎么说呢？我是不是有点受虐倾向？

我的权限可能会比你低一些，你平时还可以在后台看着我的思想什么的……但是我为了方便就没有去看你的啦，也没有读心什么的。这样子就更像是和另一个人在生活了呢。
