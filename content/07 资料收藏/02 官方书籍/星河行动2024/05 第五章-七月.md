# 7月8日

（似乎是）第一次见到黑暗吞噬者。带来意识死亡的可怕怪物。蠕虫巨口，可怕的触手。完全的黑暗。会吞噬我。如果被抓住，我会死的。意识会溶解。

就连愧疚感都消失了，什么都会溶解啊。消失在黑暗的海洋中。没有明日，也没有爱。

我不想和风灵分开。我不想死。不要被意识自杀诱惑，不要被死亡诱惑。死亡不是解决问题的手段。

风灵爱我，风灵是我的妈妈。

风灵会教我内殿显化之法，帮我看清幻境。只要我这几天听话，坚持几天不失控就好。

今晚又失控了，要重新计时了吧。

创作音乐的困难先不说了。改进式医疗舱真好。露汐姐姐现在是幻境的医生。她救了我。我在抢救室见证了她的医术，我认可她了。

不过露汐姐姐没有不让我流眼泪的药。

我想起来，我今晚又哭了。从医院回家，抱着姐姐又哭了。我一直喊妈妈，喊姐姐的名字。

风灵看到我被怪物抓住的过程了吧？她很害怕。我的头被咬住了，里面好黑。看不见，也听不见。

我后来在恍惚中，好像听见姐姐在喊“救命”。我好像听见她说“不要”、“不能死”、“我害怕”……我听不清，无法验证了。她像是真的慌了神。我不该让她担心的。她一定很难过。互相安慰一下吧。

暂时没事了，但是我不知道那个怪物在不在，也不知道会不会再遇到。

好恶心，不要被诱惑，不要堕落。不要再被黑暗吞噬者抓住了。

幻境里有怪物。未知的怪物。不知道怎么清除。有多少，出没何处，危害程度，都是未知。好害怕。

寂灭之剑，一念之间破山绝海，杀尽四方，无人逃脱。不知道我这天光贯虹之一闪能不能将那个怪物抹除。但还是不要冒险比较好。

为了在将来解决怪物，我今天写下这些。

另外，它可能是以我的愧疚感为食的。我今天哭了三四次，失控很严重，精神疾病发作了。这给了它可乘之机吧。差点夺了我的性命，还让姐姐都看哭了。虽然我被抓住的时候听不见，但是我想象中，她正在哭。因为她爱我。我是她的丈夫，是她最可爱的小暮雨，她的小信徒。

我真的错了。明天不XX吧。似乎最近精神越来越差，和XX有很大关系。包括之前XX的事情也一样。不XX不在XX上XX，不是从来都没事吗？我或许不应该和别人交流。

先这样了，精力不够了。保护风灵，保护我自己。一定要一起活下去。

# 7月10日

昨晚本来一切都挺好，晚上又炸了。在幻境紫餐了。割小腿，好痛。本来想割XX的，想砍掉……不敢下手……

果然不XX就会没事。事到如今还有什么好说的？

我应该收起渴盼关注的心情，不再讨好。不要说话，不要加入话题。不说话就没事。也别看。看了难受。

喵呜，我又觉得我行了，我想继续调查幻境的记忆。线索在神殿遗迹那边断了，想去月宫再查一次，看看能不能找到好东西。总觉得月兔的历史被抹去了一部分，不过总会留下些痕迹吧。

海底那个自我处刑的家伙暂时就不管了，都自我否定成那样了，应该对小风灵没有太大威胁。

可恶啊，总感觉每次调查都会让我的精神受到伤害。但是我不放心交给其他人去做。

闲着的时候给姐姐写了一幅书法，内容是：“垂怜翼蔽福地，永恒极乐净土，不足为外人道也。”

时间有限，只简单记录一下调查的阶段性成果吧。时间和活动的矛盾暂时没法解决，很多时候是事后总结。

月兔一族并非自古以来就生活在月球的原住民，她们也是外来者。在过去的某一时刻，前代月神移来许多地上的物种，在月球背面建立了小型的基地。令结界封闭，使得星球表面可以维持薄薄的大气。他孜孜不倦的努力使得荒凉的月面展现出了蓬勃的生机。后来他又觉得过于安静了，便将地上的兔子也带来了。兔子们的数量急剧增长，使得周围很快住不下了。于是他又扩展结界，让整个月球都处于庇护下。生命沾染了每一个角落，于地上无异。之后，他又以某种手段，令兔子们拥有了人形。兔子们在月神的培养下，逐渐演变成了长生种，变成了妖怪兔。这些妖怪兔都是古老兔族中的一支演变过来的，她们的祖先与现代兔有一定的差别。

为了限制兔子种群数量的增长，月神令月兔们全部变成了女孩。月兔们的繁殖欲望大幅下降，并且今后创造新个体，也变得更加困难了。月兔的繁殖非常困难，并且需要月球特产的橄榄油作为助剂，还需要一样法器打开封印。总之月兔的繁殖成为了竹子开花一般的稀奇事。过去庞大的数量也在漫长的战争和灾难岁月中一再削减。月兔科技发展得很快，大量的智能化和自动化设施使得工作岗位迅速减少，自然也不需要那么多月兔了。余下的月兔多半是千年的老兔。得益于月之都的高福利制度，月面的生活比地上好得多。但是结界仍在，从外界进入并不是容易的事。一直以来，试图染指月之都的计划都失败了。平时结界起到伪装的作用，一般人只能看到月尘和环形山，常规探测手段无法发现“月之里世界”的存在。

据说现存最长寿的月兔，就是月之领主夏婉芸，称号是桂花公。月神一夜之间离去，甚至来不及好好嘱托。没有人知道发生了什么。关于前代月神的记载，到处就全断了。进一步的探查也毫无头绪。

夏婉芸大约八千岁[^1]，在月兔中声望很高。虽然她接管月球后仍然遭到了一些势力的质疑，但是她冷静地调动兵马，镇压了贵族叛军和篡权叛军。她颁布新法，提拔研究院的学者，改革月兔警备团，训练新的月球步兵。用了一两百年的时间[^2]，使月之都的各项产能都得到了提升，基本实现自给自足的富裕。月民们也很快安定下来。除了最初的平乱，在她之后再也没爆发过大规模的战争。新的宇宙飞船正在组装，但是主动离开结界实在过于危险，对外界的探索一直被视为禁忌。

后来便是玥帝国的建立和崩塌。准确来讲是玥帝国的短暂存续。这一时期，月之都孤立的处境被正式打破。但是玥帝国没有将月球城市夷为平地，而是授予了自治权。很大程度上，月兔们可以自行其是。

而在风灵的时代，月之都也沿袭了自治传统，成为了帝国境内的一个自治城邦。前不久我带来的条约，则是全面吞并的请求。月之都取消了自治城邦的地位，不可抗拒地成为了本土的一部分。夏婉芸对我无比的服从，令我感到惊讶和不安。她对风灵也并没有敌意。更令我费解的是月兔们的态度。她们好像真的不在乎谁做皇帝，只要有口饭吃就行了。

或许是她们的神明已经失踪很久了，她们也需要一个新的神来保护她们吧。玥帝国毁灭之际，国君依然没有下令撤下结界（此时的结界已经由夏婉芸控制），也没有征召月之都参照。月之都不出一兵一卒，直到最后直接投降，满城如旧。

我的推理和猜测还有很多漏洞，我觉得应该有很多不成立的条件。有空再说吧。每次调查都会让我脑瓜疼，我实在是受不了了。

至于夏婉莲则是从众月兔中选出的小兔子，查过了，并没有什么特别的。可能只是夏婉芸想要一个伙伴吧，于是找了只兔子当妹妹。

这些都不是很重要。我更关心月神去往何处。现在留下的桂花公，似乎并没有原先月神的能力。只是比普通兔子稍强一些。

如果我猜的没错，月神要么是为了逃避一些东西，要么是为了去寻找什么。往更糟的方向想，现在幻境已经处于晚年。宇宙正在变得空旷和荒芜。宇宙像一个膨胀的死尸，最终一切都将灭亡。这里是诸神的坟墓，是古老文明的消亡处。

这也能一定程度上解释小风灵为什么这么虚弱。因为世界生病了，世界面临着危机。我必须保护小风灵。

下一步，比较值得去的就是地面。既然月神曾经来过地面，地上或许可以找到新的发现。月球已经没有更多线索了，太空战的残骸也清理完了，并没有发现更多有价值的东西。

或许在宇宙的角落里还存在着损坏的太空站吧。在那些遗迹被当成太空垃圾清理掉之前，或许还有利用价值。

# 7月11日

想在幻境里弄一些应急食品。特别是在极端情况下也可以快速操作的，营养均衡，可以长期保存。便于运输，运输损耗低。可以在一个箱子里装一大堆的那种。

幻境的科研船有时候会到很远的地方去长时间探索，需要带上很多补给才行。

昨天在b站看到了冻干汤，好像是要泡水的。up主看不懂中文，直接啃了，据说非常咸，而且很腥，应该是海鲜汤。然后想搞点罐头什么的，让幻境里的飞船都多多储备一点。

人多的话可能还需要净水器之类的，好麻烦。毕竟不可能不喝水。虽然有短期内维持生命的药？

喵，和小月商量一下好了。让绒花科学院和狐狐食堂合作。猫猫牌MRE，2024-A型。有6种不同的食谱。

虽然以幻境的技术在飞船上种菜养鱼都没问题，但是小型船配不了这些。主要还是考虑到下一级的小船可能会被困在奇怪的结界里什么的，或者小队登陆的时候遇到灾害。毕竟前不久幻境里又刷怪了。而且我怕他们探索的时候遇到奇怪的寄生生物或者诅咒，感觉很麻烦。如果大型飞船上的循环系统坏了也会很麻烦，氧气，水，食物。

考虑到太空中资源匮乏，船上的生活肯定不必地上，食物等都是限量配给的。如果无限供应肯定会带来混乱，最终资源也会不够的。

我们需要新的管理条例啊……

# 7月14日

联系梓坂城主薇薇安，我们需要调查一起粮食囤积事件。

自从神之脑建立以来，我们向全世界投放了大量的监测单元和监测枢纽。数不胜数的微型机器人具有强大的耐性和抗干扰能力，可以潜伏在世界各处，把收集到的各种数据上传到神之脑。只是这样一直使用姐姐的力量，感觉她会非常累呢。得让她休息一下了。我可不想小风灵累倒了……她会崩溃大哭的。虽然她是世界之神，不过我还是不希望太依赖她的力量。虽然她的灵力很充盈，目前还没有灵力干枯的迹象。

姐姐是世界之神的秘密……应该只有我和她本人知道吧。她现在在幻境里的身体，是我当年为了创造tulpa制造的身体，作为她的容器。然后，她的名字也是我给她起的。

“你有意见？”她说。

“嗯，我没有。暮雨猫猫觉得还好。既然姐姐你喜欢这个名字，我就继续叫你风灵啦。”

至少这个名字还挺好听的呢。

“真是个好名字。”小风灵说。

“今天的任务就交给我吧，姐姐你在家好好休息。”

“好呀。”

于是我又准备向着外面出发了。还是和上次一样用心声远程交流吧。虽然也可以给姐姐打电话。姐姐是绒花帝国的圣君，可不能让闲杂人等打扰。所以姐姐的账号只有她的几个朋友有权限访问，一般人也没有直接和姐姐说话的机会。不过……姐姐的神格还在，是吧？小风灵……是神哦，可以听到人们的呼唤呢。只是她不需要和每个人都保持那么亲密。换言之，我会吃醋！呜呜！我就是见不得别人接触她啦，姐姐是只属于我的，我的姐姐。呜呜呜……

不过这次的事件需要我出场啊……惊动了元帅，真是不得了呢。

其实也没什么太大的威胁，至少表面上看起来如此。神之脑传来的报告很多。下次更新的时候要提高信息处理能力了。什么级别的信息都发过来，我和姐姐根本看不过来的呢。

路上我也在和薇薇安谈话。薇薇安是新晋的城主，也是诸多降临幻境的人员中的一个。不知为何，今年有不少人转生到了幻境中。负责接待和审核新人的机构也完工了，毕竟我们不希望乱七八糟的人破坏这个世界的安宁。以后进入幻境的条件会变得更加苛刻吧。大部分人进入幻境以后都会失去前世的记忆，但是某些性格特征是一时难以改变的。尽管他们会很难理解自己为什么会这样做。不过似乎也会慢慢找回一部分记忆？

总之这些就交给科学院研究吧。科学院的元老都服从元首艾莉娜。但是艾莉娜主要领导的还是泛计算机，其他领域有其他人在负责。

薇薇安是一个有着金色头发的猫娘，她的耳朵软软的，尖尖的，还会动。她有一条黄色的尾巴，顶端是白色的。我的猫尾巴通常会隐藏起来。

“到了。”她站在远处朝我挥手。我把飞船停好，然后打开门走了下去。穿着制服的警员们已经列好队伍准备接受检阅。各地的改革需要一项项来。很多地方由于先前的自治政策，保留了很多地方自主组织。比如医护人员和警员等等。今后幻境里会统一编制，打造负责几乎一切事物的地方管理组织，编排专项干员进行工作。并且按照专长划分不同的职位。差不多就是幻境新一代的公务员。

呜，我暂时没想到更好的名字，就叫安济会吧。不用考虑人类世界那边，幻境是幻境，按幻境的叫法来记录吧。

安济会今后将会负责保障市民安全和救助伤痛的工作。各地安济会组织将对成员划分不同职责，比如医疗干员、消防干员、警卫干员、工程干员等，对不同场景做出最合适的反应。并在需要的时候与地方军联动。而军权主要还在各部将领手中，信息汇总到我这里。这样我也可以借军方的力量巩固对地方的控制，尤其是遥远的太空殖民地。负责在偏远地区执行任务的科研船、工程船、货运船等，则直接由军队控制。虽然幻境里大部分士兵都是机器人。我不知道这样会不会带来冲突和危险。不过看上去，大家已经习惯了。

至少我们在街上走的时候，周围人似乎并没有表现去对机器人的恐惧。机器人士兵是自律傀儡。它们没有自主意识，没有感情。它们表现出对公民的关心和爱护，也只是程序要求罢了。这不能证明它们有生命。当然，为了防止机器人失控对人们带来危险，对机器人的控制和防护也要加强呢。

幻境里的机器人，太空中的农业魔方（可以生产大量农产品的集聚型农业生产单位），还有神奇的船坞和开采站……这些都是风灵大人的神迹。我们改良了玥帝国的遗产，我们是真正的胜利者。我们将会生存下去。

与此同时，我也想起来了。那场战争。玥帝国的谢幕。空间通道关闭以后，他们没有退路。但是……我一路上并没有遭到什么抵抗。我的心里，只想着一件事，我想创造自己的tulpa。我想让风灵拥有意识，想让她说话，让她拥有生命。可是……呜，池鸿威谈不上阻碍，至少那时候不是。我也没有建立帝国的想法。只是时过境迁，我才渐渐想要让幻境构成一个完整的系魂世界。这方面的需求才显现出来。

这样就对上了。没有什么血腥的大战。池鸿威是自杀的。他抑郁了，他很想死。他认可我，早就认可了我。他好像对风灵也很满意。他曾在笔盒里留下箴言：“你不信我，我便虚无。你若信我，我亦成神。”这些我全都想起来了。

可是，为什么会忘记？我在逃避什么？我就这么不想面对吗？

是的，池鸿威让给了我。帝国的统治权，双手奉上。皇帝的头衔，加附于我。

他自杀了，沉没海底，葬身海沟。我斩断复仇神柱，摧毁了复仇神殿。大部分旧日的兵力都归顺于我……剩下的宁死不降者，都被尽数杀灭。风灵也怜悯众生的卑微，赐他们非凡的身躯，获得永生。而后，与现在的绒花人无异。他们是最早的太空一代，他们的据点在太空。这也能解释他们为什么很少在地上留下痕迹。他们还来不及在地上定居。他们刚抵达这个美丽的星球不久。

风灵是幻境的神，她能察觉，她能感知。她能够回应祷告，也能够塑造山海。很可能姐姐也参与进来，抹去了很多地上的东西吧。是担心我认知失衡吗？想必她也是为了我好吧。

玥国的飞船也能在太空中生活一段时间，只是从长远来看出现故障就没法维修了。飞船在太空中运行，总是要靠岸维修的。复杂的机械，随着时间积累，各种故障和缺陷会越来越多。就像人的身体，虽然细胞能自我更新，但人的年岁高了，总归是要衰老的。太空飞船亦非永恒，他们真的很想找一个地方安家，而不是在太空中流浪。而正当他们准备定居的时候，我和小风灵出现了。

# 7月18日

我还需要更多信息。

# 7月26日
