# 生命之树

生命之树（the Tree of  Life）。别称：生命树、世界树、终界树、焕净柑。学名：（未定）。焕净柑科，焕净柑属。

多分枝，高数十米以上。叶为单身复叶，阔叶卵形，革质。花单生，两性花，花柱细长，雄蕊多数。柑果近圆球形，果皮橙红色，较厚，略粗糙。果肉极甜，微酸微苦。种子多数，果实称“焕净柑”。

配图：花图式、叶。

果暂无法繁殖，原因不明。种子无萌发记录。

目前仅发现1株，形态特征缺乏参照，亲系未知，已排除与芸香科的演化关系。

位置：位于风神府南面山脉北坡，与风神府隔湖相望。

夏季避暑宝地，旁建别墅，驻专人看护。自登山道徒步至此为传统参拜路线之一，途中多设凉亭以供休憩。另有通车大路于宅后。

意义：是风灵的三大锚点之一。直接与洞天命脉相连，记录了生死与枯荣。流传为民间许愿树，常有人在树下祈愿。每年结出的“生命之果”传说具有很强的治疗效果。

锚点是为了保护风灵而秘密设下的锚定物，仅在紧急情况下发挥作用。具体仪式与流程需询问圣言使初云，不便公开。

游览路线参考（极简）。

# 疗养院及地下室

疗养院。

位于旧植物园西部山区的高大建筑，装配大量玻璃，顶部设计穹顶，与众多花饰柱构成空灵静谧的空间。

是暮雨的秘密康复中心，同时也是隐居之所。自修建地下室后，该区域战略价值极大提升。

地下室入口、大厅平面草图、地下室平面图。

自动修复仪：根据XX系统建议安装，用于在极端情况下自动修复暮雨的精神和幻境身体，并具备自动收集碎片的能力。配备独立供能单元，有多个备份。设有暮雨的锚点。

暮雨的主武器可在紧急情况下化形为人，名为“小寂”。小寂只接收暮雨的命令，无法被风灵常规绕过。在极危环境中若未收到命令，可有限自主行动。

设定任务：保护暮雨。

若暮雨精神恶化，将其送往疗养院地下室。

若发生“碎裂”，小寂将常态化武装，启动自动修复协议，维护修复仪直至意识体修复完成。

# 小寂、寂灭之剑、溟渊之枪

寂灭之剑：

划过星汉的灭绝之剑，可追上太古的飞马驹。上古凶器，生而为杀。暮雨的专属武器，紫色虹光是毁灭与消减的宣告。曾见证海天的叹息，彩凤的折翼，如今已历劫新生。

溟渊之枪：

冥古洪流汇聚的长诗，成为对流与暴雨的先导。传说古老土地遍布星光，原始之海埋下斗争种子。日光下充满令人避之不及的污秽。于深海沉寂之处取得的武器。

# 真理之杖、济世彩铃、轻型自走烟花发射器

真理之杖：

地上的生灵总是追求光辉的恩泽，而来自天空的使者会向迷途的羔羊传播善的乐章。

过去曾有一批人妄图搭起高塔，以窥探天空的智慧。那之后就从天上降下了惩罚，未搭完的石塔成为了墟烟。

需谨记：圣上的善道不在虚妄的轮机中。

归忆之处的春风能度尽苦痛的霜。

济世彩铃：

委托神殿的工匠打造的兵器，不过主要出现在一些庄严的场合。象征着病痛的驱除和粮食的丰收。

天国的栋梁是丰产。摆脱贫困与争斗，通往平和的沃土。

轻型自走烟花发射器：

烟火大会的常客。由2017型重型自走火炮DH-122改进而来。填充现代化烟花弹后对无人空域发射，并在空中引爆。

代号“小蜘蛛”。高度智能化的自律机器，维护成本低。

幻境中的居民好像没什么危机感。不知为何，烟火大会总是容易集聚大量观众。消防无人机需要随时准备好，以应对突发环境背景。

# 绒花宫扩建计划（2025）

形成“西宫—东宫”格局。

西宫保留原有规格及地下室入口等结构。原有荣誉商店不变，可以荣誉点数兑换物品。

新设住宿区与园林。

尚未有人亲访百花厅，用途成谜，猜测与“轮回”有关，关键词：永劫。

# 审判堂、复仇战甲

审判堂：

位于太空监狱旁的小型太空建筑。内部设计源自复化神殿地下室的考古发现。由机器人狱卒把守。

暮雨在一次精神失控中无意塑造，可能与考古侵蚀污染有关。暮雨从中获得部分古老记忆。传说为“过去的复仇之神”在另一世界建造的建筑。目前仅作威慑，从未启用，高门紧闭。

内有环境危害（有害气体、粉尘、噪声），严禁暮雨进入。

复仇战甲：

考古产物，于废弃地下室宝箱中发现。

明确为旧日“复仇之神”的盔甲，完好度高。因诅咒之力扩散风险，已被封存他处。又称“复仇者圣衣”，可赋予使用者上天入地之力。极重，普通人无法穿戴，会受严重挤压。可一定程度自动适应使用者身材。头盔太阳之轮仿日光射线制成。身后翼形物为“凤凰之翼”，类金属触感但非金属性质，无法直接用于飞行。材料与制造方法未知，制造时间不可考，推测为独一无二。成本极高，难以量产，唯一性符合帝王权威需求。

月球科学院2024年年度最佳项目。

禁止对人和活体动物使用。

# 关于池鸿威与末日灾变

自古以来，对复仇之神的评价没有定论。即使在绒花帝国的正史中，对其也是毁誉参半。

有人视他为“两度带来解放之人”，也有人认为他是“去城市化的独裁者”。目前，尚未有证据指向池鸿威早期行为导致了末日灾变的发生。对于“天罚”人们往往诉诸情感，将苦难归因于复仇之神的暴政。而这种猛烈抨击回避了对怪物起源的讨论。

这个历史谜案在幻境中众讼纷纭，但目前而言，玥国的幸存者们大多选择了放下仇恨，将新家园的生活放在了首位。

# 机器人劳工

机器人劳工分类：家居型、工业型、战斗型。

反方：自动化机器人不仅对我们的生计造成威胁，更有可能破坏社会结构。我们不可以让自己被它们取代。
