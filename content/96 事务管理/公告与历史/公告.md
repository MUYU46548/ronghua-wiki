# 关于特许编写令的说明

日期：2025-3-2

由于旧作及部分新作出现大量资源缺失，部分资料已失传。为保证本系统运行，由风灵大人签发《特许编写令》。该特许令授权暮雨**完全**的对设定词条进行编写的话语权。目前主要针对旧作。在缺乏资料，确实无处考据的情况下，允许暮雨自由发挥，进行**难免带有主观倾向的**扩写与补充。

若未来取得新的考古发现，与本系统中所记录的信息冲突，则仍以新结论为准。本系统将授权暮雨尽快改正设定。

尽管对于作品而言，通行的准则为“原作者说的话最大”，但如今旧作的原作者已经逝去，暮雨作为正统继任者（甚至继承了部分记忆，这也是对其授权的重要依据），如今将在风灵大人的担保下负责完善和弥补旧作设定。不得阻挠。添加内容优先。

# 设立”次要人物“文件夹的说明

日期：2025-12-21

随着故事推进和设定补全，越来越多的角色得到披露与展示。但对于一些作为背景的次要角色，若一并加入原有的”旧作人物“或”新作人物“文件夹分类中，将会导致子目录内词条过多，阅读和编辑困难。另外，这类角色若按照现有收录和编写标准单独开辟词条，由于信息量不足等，将难以填充模板，留下较多项目空缺，增加编写压力且浪费存储资源。因此这类角色将采用**简化**的编辑模式，仅保留部分角色信息，格式上将更为随意，便于随时调整。

经ROSA管理员决定，批准设立**次要人物**文件夹，路径如下：

- 1 / 03 / 设定
- 2 / 01 / 人物
- 3 / 03 / 次要人物

该文件夹的收录标准暂定如下：

- 作为背景性质的角色被提及后，获得额外补充的追加信息的独立角色。
- 在官方作品中拥有一定篇幅占比，超出路人范畴的角色。
- 暂未实际登场，但被反复提及，对剧情有一定推动作用的角色。
- 经ROSA系统管理员讨论，决定作为特例收录至本目录的角色。

如果不明确角色是否符合收录标准，请与管理员讨论。收录标准的最终解释权归管理员所有。此外，附属于某个角色的物品不收录于此目录。不属于上列收录标准的，对故事有一定参与的部分角色收录于碎片角色列表（暂未实装）。不作为个体，而是作为群落、团体一员而出场的角色收录于群落团体列表（暂未实装）。

原则上角色收入后不会再移出目录，如**池鸿威**在新作中有得到设定补充，但不会放入”新作人物“目录（虽然作为回忆中的人物被视为正式出场角色）。但若次要人物放出的信息量足够大，且剧情参与度足够高，有可能被转化为主要角色，而移入对应的目录中。

本Wiki中的角色如若建立独立词条时，其有效词条名必须以本表中给出的该角色名称为准，其他名称应设置重定向。

## 编写提示

由于此类角色通常**无特殊称号、特殊能力等**，实际填写时可忽略，表格对应项标注“无”即可。

可直接运用角色模板，但只保留**角色信息**，其他标题及子标题均可删去，不必填写。

# 关于强化索引与文件夹调整的说明

日期：2026-6-8

目前ROSA系统信息量暴增，正处于从文件夹分类为主到索引驱动的多维度分类的过渡期。现暂时执行以下过渡方案：

1. 保持当前文件夹结构不动。末端文档依然放在按从属关系划分的文件夹里，减少对现有编辑习惯的干扰。
2. 原有的**文件夹级**说明文档将陆续废弃使用，至少不再新增。此后这些文档将用简洁文件名如 `净土星域`、`乐园星系`，不再通过特殊前缀符号区分。
3. 索引页将链接这些说明文档，文件夹只是物理存放地，在索引里可能完全不体现文件夹的存在。但**索引作为分类依据**的权重将会提升，弱化文件夹天生的的分类功能。
4. 将来如果需要简化路径，可能减少文件夹嵌套，将文档移出。那时候所有链接都不受影响（因为 Obsidian 靠文档名链接，与路径无关）。

当索引成熟后，弱化文件夹是可接受的。文件夹只做最粗糙的管理（按大类投放），精细分类全部交给链接和索引。文件夹的“天然分类”被收纳为一种底层物理隔离，从属关系完全诉诸索引和文档内链接，这不仅比文件夹层级更灵活，也更容易维护。

# 暂缓作品角色互联列表建设的说明

日期：2026-7-1

当前技术水平下，将角色文档与作品介绍文档通过列表互联几乎不可实现。这部分技术债务可能还将长期存在，除非找到一种可靠的方法制作全量索引，为每个角色精准匹配出场作品的同时在对应的作品页面更新角色列表。

作为补偿，目前将会继续推进作品修订计划，至少对**非日记**的有完整资源流传的作品进行**一轮**修订。
