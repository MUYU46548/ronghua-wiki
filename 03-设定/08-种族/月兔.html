月兔

月兔

Properties1
tags月兔, 种族

2026年7月22日12分钟阅读

概述

月兔是一类兔耳人形生物，主要生活在幻境月兔之城。现存群体中无雄性个体，月兔的死亡方式是她们文明气质的重要构成。

种族介绍

  • 种族名称：月兔
  • 别名：第三版造物
  • 多样性：低
  • 代表角色：夏婉芸、妍希

生理特征

  • 形态：拥有兔耳的人形智慧生物，类似动漫中的兔耳娘（广义）。头部生有兔耳，身后有短尾。兔耳颜色以白色、黄色、黑色、浅灰、淡棕为主，个别个体呈粉色或浅金色。耳廓可随情绪转动或垂落，是情感表达的主要器官。头发颜色多样。
  • 寿命：自然寿限约800年。融光仪式完成后原可获赠额外300年寿命（上限约1100年），月神离去后赠寿功能失效，现统一为约800年。约20岁为成年认定日。月兔文化中，称自然死亡为“归还”。
  • 体征：终身保持成年巅峰状态，无明显衰老特征。成年月兔身高约150-170厘米，耳廓长度约30-50厘米，灵活可动。目前无雄性个体存在。
  • 能力：大部分月兔拥有敏锐的感知力，身体素质较普通人类略强。少数个体为法术持有者，但极为罕见。

文化与习性

  • 聚居形式： 主要聚居于月兔之城，月面大结界开放后，陆续有月兔前往其他区域生活。喜好群居，但也能接受独居生活。
  • 主要信仰：风神教、月神信仰。
  • 文化传统： 月兔文化、绒花文化。

月神信仰

月兔为月神创造的智慧生命，她们长期供奉月神，将月神视为月兔之城的君主，同时也是庇护者。

月神离去后，仍有大部分月兔保留月神信仰。信仰逐渐仪式化，新生代月兔对月神仅剩模糊印象。民间流传《鉴后录》等稗说诗集，表达对融光仪式的隐秘质疑，未被正式禁绝也未获承认。

在风灵到来后，由于宗教宽容政策，月神信仰得到保留。此后月兔仍被允许供奉月神，但风灵成为名义上的至高之主，奉献给月神的信仰需要上交一部分给风灵。

融光仪式

成年月兔在驻月鉴（或复刻分镜）前独坐七日，触碰镜中雄性影子将其沉入镜底，完成全雌化。原为单对单仪式，后发展为每年春秋两季的集体仪式。月神参加第一场后再未出席。月神离去后赠寿功能失效，仪式保留为成人礼，祭司院将“赠寿”改为“月神的祝福”。

许可仪式

许可仪式在月兔文化中通常指生育许可仪式。凡完成融光仪式的月兔，若需孕育后代，须获得月宫许可。获批者在启月鉴前完成个体仪式，仪式后约一个月内具备孕育能力。每次许可仅允一胎，一生不超过两次。未经许可者绝不具备孕育能力。

禁区敬畏

城外禁区红线由月神亲自划定，月兔视城外为需保持原生态的自然区域。1368年太空海禁颁布后禁区线彻底凝固。月兔之城对外开放后，禁区线逐渐降格为自然保护区疆界。

节日

属于月兔的传统节日主要有：

  • 银辉节
  • 玉杵节

其他节日与绒花帝国主要节日高度重合，不特别列出。

社会结构

月兔文明早期为城邦制，后建立月兔之城，由月神直接统治。月神离去后由夏婉芸（桂花公）继位执政。下设长老院（审议机构）、蓝天科学院（后改名为月球科学院，科研机构）、祭司院（管理融光仪式与许可仪式）、禁卫军（军事力量）。各城区设执政官，掌管地方行政。全雌性社会，无性别分工，社会角色由年龄、资历、能力决定。

月兔之城并入绒花帝国后，行政机构经过大幅改组。此处不展开后续变迁史。

地理与环境适应

  • 发源地： 月兔之城
  • 主要分布：绒花帝国大部，主要集中于月球、乐园星。
  • 环境适应： 偏好类似地球的自然环境，草原、森林最佳，山地、丘陵较为适宜，其他地形宜居度较低。

依赖大结界内的人造大气层与闭环生态系统。因月球无化石燃料，使用替代技术体系，如月石储能（月球特产矿石）。行动轻盈，反应迅速。

历史

若需了解月兔的完整历史，请参阅月兔线年表。

  • 创造 / 约2亿年前 / 月神降临月球，创造第一只月兔
  • 远古部落时期 / 约2亿年前-1万年前 / 分散部落，发展缓慢
  • 城邦混战时期 / 约1万年前-数千年前 / 多城邦并存，相互攻伐，人口锐减
  • 统一城邦时期 / 约数千年前 / 存留城邦向月神请示建造共同城市，月神同意。月兔之城建成，禁区红线划定
  • 全雌化确立 / 前2478年 / 月神设立融光仪式与许可机制，月兔转化为全雌性
  • 工业革命 / 文明中期 / 完成工业化，转向替代技术体系
  • 基础科学停滞 / 216年 / 理论物理锁死，应用科学横向优化
  • 大结界封闭 / 1368年 / 月面大结界启用，太空海禁颁布，禁区线凝固
  • 月神离去 / 1711年 / 夏婉芸继位，内战爆发
  • 桂花公执政 / 1713年 / 夏婉芸统治五百余年，2013年冬开启月空门
  • 对外接触 / 2020年 / 与玥国、风灵等建立联系

与其他种族关系

  • 绒花人：盟友、伙伴。在绒花帝国中，月兔与绒花人是长期共存的伙伴关系。月兔不排斥绒花人迁入月兔之城，绒花人也欢迎月兔与他们同居。
  • 兽人：友好。月兔因兔耳特征受到部分兽人的喜爱，但月兔对兽人通常无感。目前他们无公开冲突，但民间接触有限。

已知个体

代表角色

  • 夏婉芸：桂花公，月兔之城的继位者，在月神离开后继续守护族群，与风灵等人达成合作共生关系。月兔势力被整合进绒花帝国后，她依然保留部分实权，并在月兔中有着极高的威望。同时她也是已知唯一未完成融光仪式的成年月兔。
  • 妍希：善于作战的月兔，是月兔中的勇士。

其他个体

  • 婉莲：夏婉芸的近身侍从长，比夏婉芸晚出生约一百年，1756年入宫。
  • 霁云：夏宫禁卫军指挥官，460岁（1711年时），月兔之城中少数有实战经验的将领。
  • 蓝天科学院前副院长：提出探测方案被月神驳回，后成为反对派核心人物。
  • 第二城区执政官：护法军统领，叛乱失败后被流放。

其他资料

突逝的文化与社会影响

月兔对死亡有一定的文化禁忌，通常不公开讨论同类逝去的具体时辰；将自然死亡称为“归还”，仪式后死亡称为“完成”。但她们对其他种族的死亡并没有过多的忌讳。

月兔的死亡方式是她们文明气质的重要构成。

  • 不做衰老准备：月兔没有“养老”概念，没有退休制度，没有遗产传统。她们上午可能还在科学院做实验，下午就无声无息地伏在案前。
  • “归还”与“完成”：月兔语中，自然死亡（未沉淀者）称为“归还”——将寿命归还给月神。仪式后死亡（沉淀者）称为“完成”——巡礼完成，归于月壤。
  • 对突逝的恐惧与接受：年轻月兔最恐惧的是无法完成未竟之事。月兔民谣里有大量关于“那两天”的歌，歌词通常关于未竟的事、未说出口的话。但月兔不公开谈论突逝的具体时辰，因为那被视为对“归还”的不敬——不该提前计算月神的账目。
  • 与驻月渊沉睡的对比：沉睡者没有经历突逝。她们在最后48小时到来前进入沉睡，等于放弃了“归还”，选择了一种非自然的存续。这是对自然秩序的僭越，也是月神给她们的唯一特殊待遇。
